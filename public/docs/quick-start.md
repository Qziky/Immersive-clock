# 快速上手

沉浸式时钟把常用的计时、专注和展示功能集中在一个安静的全屏界面中。第一次使用不必逐项配置：先选一个适合当前场景的模式，再按需打开设置即可。

## 先熟悉操作方式

- 点击页面空白处，或按 `Space` / `Enter`，可以呼出控制面板；一段时间没有操作后，它会自动收起，让画面回归时间本身。
- 控制面板可切换模式、开始或暂停计时，并提供全屏入口。需要调整外观、课程表或环境信息时，点击左下角的设置按钮。
- 右下角的版本号可随时重新打开公告、这份快速上手、更新日志和意见反馈。

## 选择适合你的模式

- **时钟**：适合桌面常驻、会议室或教室投屏，专注呈现当前时间。
- **倒计时**：为一项任务、课程或番茄钟设置明确的结束时间。
- **秒表**：用于记录正向累积的时长，例如活动、练习或会议。
- **自习**：将时间、课程进度、语录和可选的天气、噪音状态组合成一张专注看板。

## 第一次设置建议

1. 先从时钟、倒计时或自习模式中选择当前最常用的一种，再按需进入全屏。
2. 在“设置”中调整背景、字体和显示内容，让远距离阅读也足够清晰。
3. 用于学习或教室投屏时，可添加课程表，并在自习模式中保留真正需要的信息。
4. 天气、定位和噪音监测都是可选功能；只在你打开对应功能时按提示授予权限即可。
5. 完成调整后点击设置面板底部的“保存”，再回到主界面确认实际显示效果。

## 数据与使用提示

设置、课程表和大多数历史数据默认保存在当前浏览器或桌面客户端中，不会自动同步到其他设备。时钟、倒计时、秒表和已保存的内容可在网络不稳定时继续使用；天气和在线语录等功能则需要网络连接。

## 安装指南

- **直接使用网页**：打开网页即可开始使用，适合临时计时或在公共设备上投屏。
- **安装为 PWA**：在支持的浏览器中，通过地址栏的安装图标或菜单中的“安装应用”“添加到主屏幕”完成安装；之后可像普通应用一样从桌面或主屏打开。
- **Windows、Linux 与 Android**：需要原生安装包时，可前往 GitHub Release 下载与设备匹配的版本。安装或升级前，请确认下载来源与系统类型。
- **macOS**：当前没有原生安装包，建议直接使用网页或将网页安装为 PWA。

安装后，本地设置和课程表仍保存在当前客户端；不同浏览器、桌面客户端和手机之间不会自动同步。
