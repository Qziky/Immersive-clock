# 📝 更新日志

## 🚀 v4.0.1（2026-08-06）

这是一次围绕“打开更稳、看得更清楚、说明更明白”的体验更新。没有增加喧闹的新入口，而是把兼容性、首屏体验和重要说明认真收了个尾。

### 🛠️ 修复

- 修复 QQ 浏览器部分场景下的颜色显示问题；样式表尚未准备好时，页面会先保持稳定的深色底色。
- 修复部分设备上时间区域的布局与字号异常，改善时钟、倒计时、秒表和自习时间的阅读体验。

### ⚡ 优化

- 优化启动与资源加载时序：优先展示当前页面，非关键资源在页面可用后再加载，减少首次打开时的等待感。
- 将当前页面背景默认值调整为深灰色，降低长时间展示时的视觉刺激。

### 📄 文档与说明

- 新增《用户使用协议》和《隐私政策》，集中说明本地数据、权限、第三方服务与用户体验改进计划。
- 重写公告与更新日志的组织方式，用更直接、易读的语言说明版本变化和常用操作。

## 🚀 v4.0.0（2026-08-05）

### ✨ 新增

- 重建统一界面语言与组件体系，覆盖时钟、倒计时、秒表、自习、设置与各类弹层，统一图标、设计令牌与交互模式。
- 设置中心支持响应式布局、键盘导航、焦点管理与读屏提示。
- 新增 Android 原生容器，提供正式签名 APK，并统一 Web/PWA、Electron 与 Android 的屏幕常亮行为。
- 新增完整的数据检查、选择性导出、预检、恢复与清理流程，覆盖设置、资源、噪音历史、缓存、诊断与设备状态。
- 噪音监测升级为 0–100 环境安静评分，新增设备校准档案、原始特征归档、历史评分重算与分段统计。
- 新增多标签页 Leader 协调，避免同一浏览器重复占用麦克风与重复写入历史。
- 新增本地背景图片、自定义字体等外观资源，支持实时预览、单项恢复与整体重置。
- 新增消息弹窗提醒（天气预警、分钟级降水等通知保持可见，直到用户关闭）。
- 新增公告弹窗自动关闭功能，无人操作时自动收起。
- 新增 HUD 自动隐藏与全屏展示能力。
- 新增自习时间进度模式（按日/按课表），并支持自定义自习页面各组件的显示与隐藏。
- 新增自习报告图表组件，支持多种统计图表展示。
- 旧版设置会自动迁移至设置 schema v12，IndexedDB 数据库升级至 v7。

### 🛠️ Bug 修复

- 修复了天气提醒消息过早消失、无法持续展示的问题。
- 修复了公告弹窗关闭状态与用户活动重置不一致的问题。
- 修复了关于页许可声明展示问题。
- 修复了各种已知问题。

### 🔧 优化

- 优化了语录选源、缓存、权重、顺序与故障转移，本地内容与一言、今日诗词、Advice Slip 在线渠道可组合使用。
- 优化了小米天气适配、城市定位、分钟级降水、空气质量、预警与逐小时预报编排，天气刷新与定位设置拆分为独立导航页。
- 优化了固定时间、阶段目标、课程事件、倒计时提醒与自习页面信息层级。
- 优化了主显示字体、信息字体与背景样式体系，支持场景级细调。
- 优化了组件懒加载与 SEO 预渲染。
- 优化了 Docker 多平台镜像与发布流水线，发布公开的 `ghcr.io/qziky/immersive-clock` amd64/arm64 容器镜像。
- 更新作者信息与用户文档，完善许可与合规声明。
- 提供 Web 压缩包、Windows x64 安装版/便携版、Linux AppImage/deb/rpm 与正式签名 Android APK；本次不提供 macOS 原生安装包。
- 估算 dB(A) 仍需外部参考校准，不能替代专业声级计或用于执法、职业健康与科学结论。

### ♻️ 重构

- 重构了噪音采集、评分、存储与报告模块，采用新评分模型与后台重算机制。
- 重构了设置面板与基础组件库，统一交互模式与无障碍支持。
- 重构了天气运行时与通知处理逻辑。
- 重构了公告、反馈与消息弹窗组件，统一动画与状态管理。
