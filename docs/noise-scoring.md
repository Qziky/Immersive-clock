# 环境安静评分 spectral-activity-v2

`spectral-activity-v2` 是不依赖设备基线、校准偏移或设备画像的环境安静评分。评分只消费会话几何信息和按样本轴排序的 100 ms 特征帧；dB(A) 校准属于独立诊断链。相较 v1，v2 提高了活动进入门槛并扩大平滑区间，减少普通环境声和相邻短声造成的过度扣分。

## 帧活动度

每帧使用 `rmsDbfs`、`aWeightedDbfs` 与 `sampleP01Dbfs`：

```text
K = clamp((AWeighted - P01) / max(RMS - P01, epsilon), 0, 1)
x = clamp((K - 0.68) / 0.22, 0, 1)
frameActivity = x² × (3 - 2x)
```

`frameActivity` 越接近 1，说明 A 加权能量越靠近原始 RMS、同时远离 1% 谷值，持续声学活动越明显。

## 秒级聚合

- 每秒期望 10 帧，至少 8 帧才构成有效秒。
- 有效秒活动度取该秒有效帧活动度的中位数。
- 连续 3 秒 `zeroRatio >= 0.95` 视为异常零信号，整段帧从评分中排除。
- 系统不区分异常零信号与音频处理造成的门限截断，统一报告为“信号异常”。
- 削波或系统音频处理只降低质量等级，不修改评分公式。

60 秒窗口中至少需要 48 个有效秒，即覆盖率达到 80%。不足时分数为 `null`。

## 窗口评分

```text
E = mean(最近 60 秒的有效秒活动度)
C = P20(最近 60 秒的有效秒活动度)
F = min(eventCount / 10, 1)
score = 100 × clamp(1 - 0.65E - 0.25C - 0.10F, 0, 1)
```

事件使用迟滞规则：活动度达到 `0.78` 进入事件，连续两秒低于 `0.40` 结束；间隔不超过 3 秒的事件合并，15 个事件达到事件频度项的最大扣分。

首次评分必须等待完整 60 秒。此后每 5 秒生成一个滚动 60 秒评分，不生成时长不足的临时分数。

## 派生记录

每条记录包含模型版本、源帧序列与样本范围、覆盖率、`E/C/F`、事件数、质量等级、信号健康和最终分数。主键由模型版本、会话 ID 与窗口结束帧序列组成，重复计算可幂等覆盖。

实时路径和后台重算都调用 `computeSpectralActivityScore()`。删除全部派生评分后，系统必须能仅使用会话和原始特征帧逐项重建。

## dB(A) 估算

外部参考校准只产生 `aWeightedDbfs + offsetDb` 的估算 dB(A)。它不参与环境安静评分，也不改变评分覆盖率或置信度。未校准时不显示估算 dB(A)。

## 版本规则

模型版本为 `spectral-activity-v2`，参数摘要为 `NOISE_SCORE_MODEL_CONFIG_DIGEST`。评分参数变化必须同步升级模型版本；测试锁定版本、摘要、60 秒窗口与 5 秒更新周期。
