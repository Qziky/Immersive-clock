# 数据与隐私原则

本页定义产品层面的数据边界，帮助设计、开发和宣传保持一致。它不是面向特定司法辖区的法律隐私政策；部署者仍需根据实际启用的服务、域名和分析配置提供合适的法律说明。

## “本地优先”的含义

沉浸式时钟无需账户即可使用核心时间功能。设置、课程表、倒计时、语录配置、自定义背景与字体、噪音历史等用户数据，默认保存在当前浏览器或桌面应用的数据空间中。

本地优先不等于所有功能完全离线：天气、在线语录、外部时间源、反馈问卷和可选的网站分析需要网络，并可能向相应服务发送完成请求所必需的数据。

## 数据类别

| 类别     | 典型内容                               | 默认位置       | 用户控制                         |
| -------- | -------------------------------------- | -------------- | -------------------------------- |
| 设置     | 启动模式、显示开关、提醒阈值、渠道配置 | 当前设备       | 修改、备份、恢复、重置           |
| 学习内容 | 课程表、目标日期、自定义语录           | 当前设备       | 编辑、导入、备份、删除           |
| 外观资源 | 本地背景图片、字体及引用关系           | 当前设备       | 导入、应用、删除、清理未使用资源 |
| 环境历史 | 安静评分、估算值、统计与监测时间       | 当前设备       | 查看、备份、清理                 |
| 监测特征 | 用于本地重算的声音特征，不是可回放录音 | 当前设备       | 导入、重算、随相关数据清理       |
| 缓存     | 天气、语录、版本和请求状态             | 当前设备       | 自动更新、手动清理               |
| 诊断     | 按所选模式记录的错误摘要               | 内存或当前设备 | 关闭记录、查看、清理             |

## 权限原则

### 麦克风

- 仅在噪音监测或校准需要时请求权限。
- 当前采集链路在设备本地提取声音特征，不向项目服务器上传麦克风音频，也不保存可回放录音。
- 用户可以选择输入设备、停止监测、清除校准与历史。
- 浏览器或操作系统始终是权限的最终控制者。

### 定位

- 自动定位优先使用浏览器定位；失败时可使用公共 IP 进行较粗略的降级定位。
- 用户可以改用手动城市，避免持续依赖高精度定位。
- 为查询天气，坐标、城市标识或搜索词会被发送到天气服务或部署的天气代理。

### 通知

- 仅在需要系统通知且获得授权时使用。
- 拒绝通知权限不应阻止应用内天气和环境信息展示。

## 外部数据流

| 功能           | 可能连接的服务                                 | 可能发送的数据                             | 说明                                                           |
| -------------- | ---------------------------------------------- | ------------------------------------------ | -------------------------------------------------------------- |
| 天气与城市解析 | 小米天气接口或部署代理、公共 IP 定位服务       | 坐标、城市标识、城市搜索词、IP 请求信息    | 用于当前天气、降水和预警；以实际部署配置为准                   |
| 在线语录       | 一言、今日诗词、诗泉、Advice Slip 等已启用渠道 | 渠道参数、分类/朝代/体裁及常规网络请求信息 | 可关闭渠道；诗泉直连 `poetry.palemoky.com`；本地内容可作为降级 |
| 时间校准       | 用户选择的 HTTP、Time API 或桌面 NTP 服务      | 请求时间、目标地址及常规网络信息           | 默认设备时间仍可使用；自定义地址由用户负责信任判断             |
| 意见反馈       | 腾讯问卷                                       | 用户主动填写的内容及问卷服务收集的信息     | 在独立反馈页中提交，不属于本地备份                             |
| 网站分析       | Microsoft Clarity                              | 由 Clarity 配置定义的访问与交互信息        | 仅在生产构建被部署者显式启用并配置项目 ID 时初始化             |
| 项目与社区链接 | GitHub、作者网站、QQ 等                        | 常规网页访问请求信息                       | 用户点击后离开当前应用环境                                     |

部署版本可能改变代理位置、是否启用分析及外部域名。宣传和隐私说明应描述实际部署，而不能仅根据源代码默认值作绝对承诺。

## 备份与导出

- 备份文件为明文，可能包含位置、课程安排、语录、自定义资源和噪音活动时间。
- “完整备份”可包含噪音历史；“设置与资源”范围不包含噪音历史。
- 恢复前应展示来源格式、包含的数据域、大小和风险提示。
- 用户应像保管课程表或个人记录一样保管备份文件，不应随意上传到公开渠道。

## 产品设计要求

- 权限请求前说明用途，不把权限拒绝描述成用户错误。
- 新的外部请求必须能回答：发送什么、为什么发送、何时发送、如何关闭。
- 新的数据域必须定义查看、导出、迁移、清理和失败恢复方式。
- 删除和重置必须清楚区分，默认选择影响更小、可恢复性更高的操作。
- 宣传不得使用“绝不联网”“零数据收集”或“完全匿名”等无法覆盖所有部署配置的绝对表述。
- 引入账户、云同步或新的分析服务前，必须重新评审本页及用户说明。
