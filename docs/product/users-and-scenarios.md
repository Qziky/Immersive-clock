# 用户与场景

## 第一优先用户

### 教室与自习空间的展示管理者

可能是教师、班委、值日同学、自习室运营者或活动组织者。他们需要在大屏上持续展示时间、课程和提醒，同时尽量减少现场操作。

核心任务：

- 让教室各个位置都能快速读到时间。
- 在上课、自习或活动期间展示下一安排、目标日期和必要提醒。
- 预先配置界面，在现场以很少的操作切换模式。
- 在网络波动时保留基本时间展示和已有设置。

### 学生与备考群体

他们需要比普通时钟更有学习语境的工具，但不希望花大量时间维护任务系统。

核心任务：

- 看清当前时间、学习进度和重要日期。
- 使用倒计时或秒表完成一次明确的学习任务。
- 通过课程表、语录和环境信息保持节奏。
- 了解环境是否比平时更嘈杂，而不是获得实验室级声学测量。

## 第二优先用户

### 个人专注工作者

在电脑或平板上长期展示时间，希望界面简洁、可调整并能保存个人偏好。

### 演示、直播与活动使用者

需要一个稳定、干净的全屏时间画面作为活动看板或画面元素。这类场景受益于外观定制，但不应推动产品加入复杂的媒体制作工作流。

## 核心场景

| 场景       | 用户要完成的事                     | 产品应优先保证                         |
| ---------- | ---------------------------------- | -------------------------------------- |
| 教室大屏   | 远距离查看时间和当前学习信息       | 大字可读、层级稳定、低干扰             |
| 晚自习     | 同时关注时间、课程、天气和环境状态 | 信息可配置、提醒克制、长时间稳定运行   |
| 备考倒计时 | 展示快捷考试或自定义目标日期       | 目标明确、多事件可管理、不过度制造焦虑 |
| 临时计时   | 启动倒计时或秒表                   | 少步骤、状态清楚、提示可靠             |
| 个人桌面   | 将应用作为常驻时钟                 | 外观舒适、可安装、偏好可保存           |
| 环境回顾   | 查看一段自习期间的安静程度         | 趋势可理解、数据口径诚实、历史可清理   |

## 典型使用旅程

### 首次投屏

1. 打开网页或已安装应用。
2. 通过新手指引认识模式切换、HUD 和设置入口。
3. 选择自习模式，决定要展示的顶部信息、课程和倒计时。
4. 根据屏幕和环境调整字体、颜色与背景。
5. 保存后进入全屏，让控制界面自动退场。

### 日常自习

1. 直接进入上次使用或指定的启动页面。
2. 查看时间、下一课程和天气状态。
3. 在需要时开启麦克风权限，使用环境安静评分。
4. 自习结束后查看报告，按需备份或清理历史。

## 设计时必须照顾的条件

- 屏幕尺寸从手机、桌面显示器到教室大屏不等。
- 使用者可能离屏幕较远，也可能只使用键盘或触摸操作。
- 校园网络可能不稳定，外部天气和语录服务可能暂时不可用。
- 公共设备可能由多人轮流使用，本地保存的信息应允许检查和清理。
- 麦克风、定位和通知权限可能被拒绝；拒绝权限后核心时钟仍必须可用。

## 不以这些人群为核心

- 需要多人共享日历、任务分派与审批的组织团队。
- 需要跨设备账户同步和云端协作的重度效率用户。
- 需要法定时间源、专业气象决策或合规声学测量的专业机构。
- 希望用一个应用替代完整桌面环境、媒体播放器或数字标牌管理平台的用户。
