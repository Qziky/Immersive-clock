# 能力地图

本页描述当前产品已经形成的能力边界，不等同于路线图。具体操作方式见[使用说明](../user-guide/README.md)，实现细节见[技术知识库](../technical/README.md)。

## 1. 时间模式

### 时钟

- 全屏显示当前时间与日期。
- 可选择是否显示秒数，并调整字体、颜色、透明度和背景。
- 支持通过路径直接进入对应模式，适合书签和固定展示入口。

### 倒计时

- 设置时长后启动、暂停和重置。
- 结束时提供声音提示。
- 保持清楚的运行、暂停和结束状态，避免把装饰效果放在计时准确性之前。

### 秒表

- 支持启动、暂停与重置。
- 以高频显示满足短时计量，同时将长期运行的正确性放在首位。

### 自习

- 将时间、日期、天气、噪音、语录、课程进度和事件倒计时组织为一个学习看板。
- 各辅助组件可独立显示或隐藏，主时间始终保持核心位置。
- 顶部信息可以轮播学习进度、下一课程、降雨、天气预警和自定义文本。

## 2. 学习组织

### 课程表

- 管理课程或自习时间段。
- 支持基于 CSES v2 的 YAML 导入和导出，在覆盖草稿前校验周期、引用、时间与重叠，并支持 `rest_count: 1` 的单休兼容扩展。
- 为“下一课程”和课程进度等上下文信息提供基础。

### 目标日期

- 支持高考、中考、考研、考公快捷目标，单个自定义事件和多个事件轮播。
- 每个事件可设置名称、日期、顺序及部分视觉样式。
- 目标日期用于提供方向，不引入完整任务管理或打卡体系。

### 启动与信息编排

- 可指定刷新或下次启动时默认进入的模式。
- 可调整自习组件、信息来源及轮播节奏。
- HUD 在交互后出现、无操作后隐藏，兼顾可发现性和沉浸展示。

## 3. 环境感知

### 天气与定位

- 支持浏览器高精度定位、公共 IP 降级定位和手动城市。
- 展示当前天气，并提供分钟级降水、气象预警、空气质量及日出日落相关提醒选项。
- 有缓存、请求保护和跨标签页协调；服务不可用时允许展示已有数据或明确降级状态。

### 噪音监测

- 经用户授权后，从选定麦克风提取短时声音特征。
- 默认以“环境安静评分”表达同一设备和相近使用条件下的相对变化。
- 经外部参考声级校准后，可显示估算 dB(A)。
- 提供实时趋势、统计、历史报告、保留设置和设备校准管理。
- 原始特征可用于本地重算，但产品不把自己定位为专业录音或声级计工具。

## 4. 内容与氛围

### 语录

- 内置本地内容，并可组合多个在线语录渠道。
- 支持渠道启停、权重、分类和本地自定义内容。
- 支持自动轮换、手动刷新、自然打字、平滑显示和直接显示。
- 在线服务失败时优先保持已有或本地内容可用。

### 外观

- 统一设置主显示字体、信息字体和整体背景。
- 支持纯色、渐变、本地背景图片和本地字体资源。
- 可针对时间模式、自习语录和顶部信息栏做更细的视觉调整。
- 提供预览、单项恢复和整体重置，保证个性化是可逆的。

## 5. 数据与可维护性

- 设置、课程、外观资源、缓存、诊断和噪音历史按数据域管理。
- 支持完整备份，或只备份设置与资源。
- 恢复前展示预检摘要，并允许决定是否包含噪音历史。
- 可分别清理缓存、噪音历史、诊断记录和未使用资源。
- 重置操作明确告知影响范围，避免把所有本地内容一并抹除。

## 6. 平台与体验基础

- Web 版可直接访问；PWA 支持安装、离线基础资源和自动切换更新资源。
- Electron 提供 Windows 与 Linux 桌面打包能力，以及桌面环境中的时间同步和天气代理能力。
- 核心页面支持键盘、触摸和响应式布局。
- 首次使用提供引导；公告、更新日志和意见反馈可从应用内访问。

## 能力依赖与降级

| 能力                   | 依赖                                 | 不可用时的合理表现                     |
| ---------------------- | ------------------------------------ | -------------------------------------- |
| 基础时钟、倒计时、秒表 | 当前设备                             | 保持核心显示和本地操作                 |
| PWA 离线               | 浏览器与已缓存资源                   | 回到普通网页能力                       |
| 天气                   | 网络、位置或手动城市、第三方天气服务 | 使用缓存或显示明确状态，不阻塞时间模式 |
| 在线语录               | 网络与第三方语录服务                 | 使用本地或缓存内容                     |
| 噪音监测               | 麦克风、权限和 Web Audio 支持        | 隐藏数据或提示授权，不影响其他组件     |
| 估算 dB(A)             | 外部参考校准                         | 继续显示环境安静评分                   |
| 浏览器通知             | 系统和浏览器权限                     | 在应用内展示可用提醒                   |
| NTP 校时               | Electron 桌面环境                    | 使用其他时间源或本机时间               |
