# 产品知识库

这里定义沉浸式时钟长期不应轻易改变的产品方向：为谁服务、解决什么问题、以什么方式解决，以及哪些事情明确不做。

产品文档不是版本日志，也不是功能操作手册。当前界面如何使用，请前往[使用说明](../user-guide/README.md)；实现原理与工程约束，请前往[技术知识库](../technical/README.md)；对外传播时使用的标准素材与文案，请前往[宣传资料](../marketing/README.md)。

## 品牌初心

> 让时间管理更优雅，让学习更专注。

沉浸式时钟希望把“看时间”从一个频繁打断注意力的动作，变成安静、清晰、随时可读的环境信息。它优先服务校园、自习空间与大屏展示，同时也适合个人学习和专注工作。

## 阅读与维护规则

- 讨论“为什么做、为谁做、做成什么样”时，以本目录为准。
- 产品定位变化必须同步检查 README、使用说明和宣传口径，避免四处出现不同答案。
- 新功能不因“技术上能做”就自然成立；必须能落入既有用户场景和能力支柱。
- 版本号、依赖版本、接口地址与实现细节不写在这里，防止产品原则被短期工程变化淹没。
- 未上线的设想必须明确标注为规划，不得与当前能力混写。
