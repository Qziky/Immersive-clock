# 天气、定位与提醒

## 天气功能能显示什么

自习页顶部可以显示当前城市、天气和温度。更完整的信息位于“设置 → 环境提醒 → 天气服务 → 数据”，包括：

- 当前天气与体感信息；
- 未来分钟级降水；
- 逐时和逐日预报；
- 空气质量；
- 天气预警；
- 日出日落；
- 接口返回状态和更新时间。

天气与城市搜索使用小米天气服务。第三方数据可能延迟、缺失或临时不可用，不应将本应用作为灾害预警或专业气象判断的唯一来源。

## 选择定位方式

打开“设置 → 环境提醒 → 定位服务”。这里同时显示定位设置和当前定位状态。

### 自动定位

自动定位按以下顺序工作：

1. 请求浏览器提供高精度坐标。
2. 用坐标解析天气城市。
3. 如果浏览器定位失败、超时或被拒绝，尝试使用公共 IP 推测城市级位置。

定位状态会明确显示来源：

- **高精度浏览器定位**：可查看浏览器返回的大致精度。
- **公共 IP 降级定位**：只能粗略判断城市，学校网络、代理、VPN 或运营商出口可能让城市偏差很大。

点击“刷新高精度定位”会重新请求浏览器定位。若之前选择了“拒绝且不再询问”，需要先在浏览器或系统权限中改为允许。

### 手动城市

自动定位不准时，推荐改为手动城市：

1. 选择“手动城市”。
2. 输入城市名称；同名地区较多时加上省份或地区，例如“浙江 杭州”。
3. 点击“搜索城市”。
4. 从搜索结果中选择准确城市。
5. 点击设置面板底部“保存”。

只输入文字但没有从候选结果中选择城市，不能保存。保存后，应用会复用所选城市，不再依赖浏览器高精度定位。

## 天气更新

在“天气服务 → 更新”可以查看：

- 上次成功更新时间；
- 下次计划更新时间；
- 当前运行状态；
- 本小时天气请求数量；
- 最近错误。

正常情况下，应用会自动安排更新：前台完整天气约每 10 分钟一次，页面在后台时约每 30 分钟一次；接近降雨或正在降雨时，分钟降水会自动加快。启动、回到前台或网络恢复时，只会刷新已经过期的数据。

点击“刷新天气”可以强制请求一次最新数据。频繁点击仍会受到内部请求保护，出现“等待请求保护”不代表应用损坏，稍后再试即可。

网络失败时，应用可能继续显示同一定位方式下最近一次成功数据，并标记为过期。离线时不会不断发送请求。

## 天气提醒

“天气服务 → 提醒”提供三个独立开关：

- **天气预警弹窗**：恶劣天气预警触发时显示弹窗。
- **空气污染提醒**：空气质量较差时显示提醒。
- **日出日落提醒**：接近日出或日落时显示提醒。

重要说明：

- 关闭自习页顶部的“天气”组件不会自动关闭这些提醒。
- “天气预警弹窗”和自习页“顶部进度与信息”中的“天气预警”是两个独立入口。
- “短时降雨”也需要在“常用工作台 → 自习显示 → 顶部进度与信息”中添加，才能作为顶部信息出现。
- 天气预警弹窗会保留到用户主动关闭，不会在几秒后自动消失。

## 在顶部显示短时降雨

1. 确认定位和天气数据正常。
2. 打开“设置 → 常用工作台 → 自习显示”。
3. 在“顶部进度与信息”中添加“短时降雨”。
4. 选择提前 10、15、30、60 或 120 分钟显示，并选择后方使用 24 小时进度还是课时进度。
5. 保存设置。

只有在定位、发布时间和分钟预报都可信时，应用才会显示确定的开始或结束倒计时。数据过期、接口失败或时间信息不可靠时，会避免给出看似精确但可能错误的分钟数。

## 隐私与网络请求

- 高精度自动定位需要浏览器提供坐标，坐标会用于城市解析和天气请求。
- 自动定位失败后，公共 IP 服务会根据当前公网出口推测位置。
- 手动城市会保存所选城市和城市中心坐标。
- 这些设置和最近天气缓存保存在当前设备，也可能包含在设置备份中。
- 天气功能依赖网络和第三方服务；如不希望发送定位相关请求，可隐藏天气、关闭提醒，并不要启用自动定位。仅隐藏顶部天气不会停止运行时天气功能。

## 常见问题

### 一直显示“定位中”

先检查浏览器定位权限和网络，再点击“刷新高精度定位”。仍无结果时切换为手动城市。

### 自动定位到了其他城市

如果来源显示“公共 IP 降级定位”，这是城市级估算。VPN、代理、校园网或运营商出口都可能导致偏差，直接使用手动城市最可靠。

### 天气卡片隐藏了，为什么还有预警

组件显示与提醒开关彼此独立。请到“环境提醒 → 天气服务 → 提醒”关闭对应弹窗，或在“自习显示”中移出天气预警、短时降雨条目。

### 数据页有旧内容

查看“天气服务 → 更新”的状态和上次更新时间。离线或接口失败时，旧缓存会暂时保留，手动刷新成功后才会替换。

更多排查见[常见问题与故障排查](faq-and-troubleshooting.md)。
