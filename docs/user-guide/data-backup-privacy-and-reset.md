# 数据备份、隐私与重置

## 数据保存在哪里

沉浸式时钟没有用户账号和云同步。设置、课程表、事件倒计时、本地语录、自定义字体与背景、天气缓存、噪音历史和诊断信息默认保存在当前浏览器、PWA 或桌面客户端中。

因此：

- 换浏览器、换设备或换系统账户后，数据不会自动出现；
- 无痕/隐私窗口关闭后通常不会保留数据；
- 清除网站数据、重置浏览器或卸载时选择删除应用数据，可能造成永久丢失；
- 浏览器存储空间不足时，可重新生成的缓存或未获得持久存储保护的数据可能被回收。

重要配置完成后，建议立刻创建备份。

## 查看本地数据概览

打开“设置 → 系统数据 → 设置数据”，页面会统计：

- 应用数据总量；
- 用户数据：设置、资源和历史；
- 可清理缓存；
- 浏览器提供的已用空间与配额；
- 原始监测帧、采集会话和后台评分重算状态。

如果应用发现损坏或由更高版本生成的设置，会把原始内容隔离，避免直接覆盖当前配置。你可以先下载隔离副本再决定是否删除。

## 创建 JSON 备份

“创建备份”有两种范围：

| 范围       | 包含                                                                     | 不包含                                 |
| ---------- | ------------------------------------------------------------------------ | -------------------------------------- |
| 完整备份   | 设置、课程表、事件倒计时、语录配置和内容、自定义字体与背景、派生噪音历史 | 原始噪音特征、缓存、诊断记录、设备状态 |
| 设置与资源 | 设置、用户内容、自定义字体与背景                                         | 噪音历史、原始噪音特征、缓存、诊断记录 |

操作步骤：

1. 选择备份范围。
2. 阅读明文文件提示。
3. 点击“创建备份”。
4. 把下载的 `.json` 文件保存到可信位置。

备份文件没有加密，可能包含位置、课程安排、语录、背景资源和噪音活动时间。不要直接上传到公开网盘、聊天群或代码仓库。

## 从备份恢复

1. 在“从备份恢复”中选择沉浸式时钟 JSON 文件。
2. 等待本机预检完成。
3. 检查备份范围、应用版本、内容数量、数据分类和警告。
4. 如果备份含噪音历史，决定是否勾选恢复该分类；设置与自定义资源始终恢复。
5. 点击“恢复并刷新”并再次确认。

预检期间不会修改本地数据。确认恢复后，对应分类会被备份内容替换，设置面板中尚未保存的草稿会丢失，应用随后自动刷新。

更高版本应用生成的备份、损坏文件、不安全资源或不支持的旧噪音历史可能被拒绝。不要手工修改备份，除非你清楚格式要求并保留原文件副本。

## 迁移到其他设备

建议按这个顺序：

1. 在旧设备创建“完整备份”。
2. 如需保留可重新计算的原始监测数据，另外按日期导出 `.icnoise`。
3. 在新设备打开同版本或更高兼容版本的应用。
4. 先恢复 JSON 备份并等待刷新。
5. 再导入 `.icnoise`，等待后台重算完成。
6. 重新授权位置和麦克风；这些系统权限不会随备份迁移。

## 原始噪音数据与 `.icnoise`

常规 JSON 备份不包含原始噪音特征。需要时到“原始监测数据”：

- 选择开始和结束日期；
- 点击“导出 `.icnoise`”；
- 在目标设备选择 `.icnoise v1` 文件；
- 查看会话、分块、帧数、日期范围和预计新增空间；
- 点击“导入并重算”。

导入确认前不会写入数据。相同内容可安全重复预检；文件冲突、损坏或空间不足时会整次拒绝，避免只导入一半。

`.icnoise` 不包含可播放 PCM 音频，但仍能反映监测时间和环境活动，请按敏感数据保管。

## 分类清理

可以只清理一种数据，而不影响其他内容：

- **临时缓存**：天气、在线接口状态和可重新获取的离线缓存；保留个人设置和历史。
- **噪音历史**：删除采集会话、原始特征、派生评分和重算状态；保留监测设置与 dB(A) 校准。
- **诊断记录**：删除错误中心和本机诊断，不改变后续记录方式。
- **未使用资源**：只删除没有被任何外观设置引用的字体和背景。

如果外观还有未保存草稿，需要先保存或取消，才能安全清理未使用资源。

## 恢复默认与全部删除

这两个操作区别很大：

- **恢复默认设置**：重置显示、提醒、天气、噪音和外观等偏好；保留课程表、事件倒计时、语录内容、历史、自定义字体和背景。
- **删除全部本地数据**：永久删除本应用登记的设置、记录、资源、缓存、诊断和设备状态，相当于在当前设备重新开始。

两者都会丢弃设置面板中尚未保存的更改，并在完成后刷新。执行“删除全部本地数据”前，先创建需要的 JSON 和 `.icnoise` 备份。

## 哪些数据会联网

本地保存不代表所有功能都完全离线：

- 天气和城市搜索会向天气服务发送坐标、城市或位置标识；
- 自动定位失败时，公共 IP 定位服务会看到当前公网 IP；
- 在线语录会连接一言、今日诗词、诗泉或 Advice Slip；诗泉请求会向
  `poetry.palemoky.com` 发送语言以及用户选择的朝代、体裁筛选；
- 意见反馈会打开第三方问卷页面；
- 生产部署可按配置启用网页使用统计，是否启用由具体部署环境决定。

麦克风监测在当前设备处理，不保存可回放录音；本地背景和字体进入应用自己的本地资源库，不会作为天气或语录请求上传。备份文件只有在你主动下载、复制或分享时才离开设备。

如使用共享电脑，结束后至少退出全屏并检查设置数据；涉及课程、位置或噪音记录时，建议导出所需内容后执行“删除全部本地数据”。
