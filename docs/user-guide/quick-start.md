# 快速开始

## 打开应用后先做什么

首次访问时，应用可能自动开始新手指引。跟随提示可以认识模式切换、自习页、设置和噪音历史；如果暂时不想看，可以关闭，之后在“时钟”页面左下角点击问号重新播放。

主界面默认只突出时间。控制按钮隐藏时：

- 点击页面空白处；或
- 按键盘 `Space` / `Enter`。

页面中央会出现 HUD 控制面板。HUD 大约 8 秒没有操作后自动隐藏；当键盘焦点还在 HUD 内时不会强行消失。

## 认识四种模式

在 HUD 顶部选择：

- **时钟**：显示当前时间和日期。
- **倒计时**：设置一个小时、分钟、秒倒计时。
- **秒表**：开始、暂停和重置累计时间。
- **自习**：把时间、课程进度、天气、噪音状态、事件倒计时和语录组合成投屏看板。

HUD 底部始终提供“全屏”；倒计时和秒表模式还会显示对应的开始、暂停和重置按钮。

## 打开设置

点击左下角的设置按钮。设置分为五组：

1. **常用工作台**：启动页面、自习显示、倒计时和课程表。
2. **视觉外观**：整体样式、时间、语录和顶部信息栏。
3. **环境提醒**：噪音、天气和定位。
4. **内容语录**：刷新、显示效果和语录渠道。
5. **系统数据**：时间校准、项目信息、备份清理和错误调试。

设置面板底部有两个关键按钮：

- **保存**：一次保存本次访问过的设置分区并关闭面板。
- **取消**：放弃未保存的草稿；外观预览也会恢复到已保存状态。

备份、恢复、分类清理和“危险操作”属于立即执行的数据操作，不必再点击设置面板的“保存”。恢复或重置完成后，应用可能自动刷新。

## 第一次使用建议

如果用于教室、自习室或大屏，建议按这个顺序配置：

1. 在“常用工作台 → 启动页面”选择“自习”。
2. 在“常用工作台 → 课程表”录入实际课时。
3. 在“常用工作台 → 自习显示”保留需要的组件，并整理“顶部进度与信息”。
4. 在“环境提醒 → 定位服务”确认城市。
5. 如需噪音监测，在“环境提醒 → 噪音监测”授权麦克风并设置提醒分数。
6. 在“视觉外观”检查投屏距离下的字号、颜色和背景对比度。
7. 点击“保存”，返回主界面后再进入全屏。

## 权限提示

应用可能请求以下权限：

- **位置信息**：用于自动定位天气城市；拒绝后会尝试公共 IP 城市级定位，也可改用手动城市。
- **麦克风**：只在启用环境监测时使用；拒绝后，噪音评分、报告和校准不可用。
- **本地存储**：浏览器会保存设置、资源和历史。清理网站数据、使用隐私模式或浏览器自动回收空间都可能导致内容丢失。

## 快速检查是否配置成功

- 切换模式后，浏览器地址会对应当前模式；从根入口重新打开时会使用“启动页面”设置，直接刷新带模式路径的页面则会保留该模式。
- 自习页中央时间始终存在，其他组件可按需隐藏。
- 天气旁能看到城市和实时信息；若仅显示旧数据，请到“天气服务 → 更新”手动刷新。
- 噪音区从“初始化中”进入“采集中”，积累足够有效数据后显示评分。
- 点击右下角版本号可以重新打开公告、更新日志和意见反馈。
