# 自习模式与课程表

## 自习页由哪些部分组成

自习页适合教室、自习室、图书馆、会议室和个人专注场景。页面分为三块：

- **顶部信息栏**：天气、噪音、进度与提示、事件倒计时。
- **中央区域**：当前时间和可选日期。
- **语录区域**：本地或在线语录。

中央时间始终显示。其他内容都可以在“设置 → 常用工作台 → 自习显示”中打开或关闭。

## 选择要显示的组件

在“自习显示 → 显示设置”中可控制：

- 天气；
- 噪音监测；
- 事件倒计时；
- 励志语录；
- 日期。

隐藏顶部天气只是不在看板上显示天气卡片，不会自动关闭天气数据刷新、天气预警、空气质量提醒、日出日落提醒或已配置的短时降雨信息。

## 配置顶部进度与信息

“顶部进度与信息”把进度和临时提示放在同一队列中。可以添加：

- **24 小时进度**：展示今天从 00:00 到 24:00 的进度和时段问候。
- **课时/课间进度**：根据课程表展示当前课时或课间进度。
- **下一课时**：提示下一节课程及临近程度。
- **短时降雨**：天气数据可信且进入设定时间窗时显示。
- **天气预警**：展示当前有效预警的摘要。
- **自定义文案**：例如“记得完成今日复盘”。

使用方法：

1. 从“添加信息”中选择项目。
2. 通过拖动、上移或下移调整顺序。
3. 对下一课时、短时降雨、天气预警或自定义文案选择背景进度。
4. 对下一课时或短时降雨设置显示时机。
5. 不需要时点击移出；被移出的自定义文案会保留，可稍后恢复。选择“永久删除”才会彻底删除文案。

最多启用 20 条。启用两条或更多时会自动轮播，间隔可设为 3–30 秒；提醒信息到达重要时间点时会提高优先级。鼠标悬停、键盘聚焦或页面进入后台时，轮播会暂停；点击当前信息或按 `Enter` / `Space` 可手动切换。

如果没有启用任何条目，这一块会隐藏。短时降雨数据过期、缺少可信时间或定位不可用时，不会显示确定的降雨倒计时。

## 配置事件倒计时

“设置 → 常用工作台 → 倒计时”控制的是自习页顶部的事件倒计时，与独立的“倒计时模式”不同。

可以选择：

- **快捷事件**：统一选择高考、中考、考研或考公，并按目标年份自动计算常用考试日期。
- **单事件**：填写事件名称和日期。
- **多事件**：添加快捷事件或自定义项目，排序后按设定秒数轮播。

中考、考研和考公的具体日期可能因地区或年度安排调整；如果实际日期与预设不同，请使用“单事件”填写正式日期。

多事件模式下，列表顺序就是展示顺序。保存设置后，目标和顺序才会应用到自习页。

## 编辑课程表

打开“设置 → 常用工作台 → 课程表”。课程表工作台分为四个区域：

- **概览与文件**：查看今天是周期中的第几个上课日，并导入或导出 CSES YAML；
- **课程库**：维护课程名称、简称、教师和地点；
- **日课程表**：选择课程、设置秒级开始/结束时间，并指定它在哪些上课日启用；
- **周期与锚点**：设置上课/休息 spans，以及周期第 1 天对应的实际日期。

一个实际日期先根据周期锚点映射到 `work` 或 `rest` span；只有上课日才会加载
`enable_day` 匹配的日课程表。同一上课日可匹配多个日课程表，它们的课时会合并并统一检查重叠。

课程重命名会同步更新全部课时引用。仍被课时引用的课程不能直接删除；需先从日课程表中移除
相关课时。课时支持添加、复制、上移、下移、删除和按开始时间排序。

所有编辑都先保存在设置草稿中。点击“恢复已保存”会放弃当前课表草稿；“重置默认模板”会恢复
固定周一锚点的上 5 休 2 工作日模板。两种操作都需要点击设置面板底部“保存”才会正式生效。

## CSES YAML 导入与导出

课程表支持 UTF-8 的 CSES v2 `.yaml` / `.yml` 文件，并额外支持 `rest_count: 1` 的单休周期：

1. 在“概览与文件”中选择 CSES YAML。
2. 应用会严格检查所支持的版本、周期、课程引用、`HH:mm:ss` 时间和实际启用日上的重叠。
3. 校验通过后点击“覆盖当前草稿”；导入不会立即写入已保存设置。
4. 确认周期锚点。CSES 文件不包含这个应用私有日期，因此导入会保留当前锚点。
5. 点击设置面板底部“保存”。

校验失败时会显示字段路径，并保持当前草稿不变。“导出 YAML”导出当前已通过校验的草稿，
不会自动保存，也不会把周期锚点写入 CSES 文件。

`rest_count: 1` 可用于上 6 休 1 等单休作息，是本应用的兼容扩展。应用可正常保存、导入和
导出此类文件；部分严格 CSES v2 工具可能无法识别它。

## 噪音报告与课程表的关系

启用自动弹出报告后，应用会在当前课时结束前约 1 分钟打开该课时的噪音报告。同一课时手动关闭后不会反复弹出。自动关闭时长只影响这种自动弹出的报告；从历史记录打开的报告会一直保留，直到你主动关闭或返回。

报告依赖有效监测数据。课程表本身不会开启麦克风，也不会在没有噪音数据时制造评分。

## 投屏前检查清单

- 课程时间是否与当天实际安排一致；
- 顶部信息是否过多，远距离能否看清；
- 背景与文字对比度是否足够；
- 天气城市是否正确；
- 麦克风权限是否已授权，提醒音量是否合适；
- 浏览器和系统是否已关闭自动休眠；
- 如需保留历史，是否已开启“保存监测数据”。
