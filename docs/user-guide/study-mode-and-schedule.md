# 自习模式与课程表

## 自习页由哪些部分组成

自习页适合教室、自习室、图书馆、会议室和个人专注场景。页面分为三块：

- **顶部信息栏**：天气、噪音、进度与提示、事件倒计时。
- **中央区域**：当前时间和可选日期。
- **语录区域**：本地或在线语录。

中央时间始终显示。其他内容都可以在“设置 → 常用工作台 → 自习显示”中打开或关闭。

## 选择要显示的组件

在“自习显示 → 显示设置”中可控制：

- 天气；
- 噪音监测；
- 事件倒计时；
- 励志语录；
- 日期。

隐藏顶部天气只是不在看板上显示天气卡片，不会自动关闭天气数据刷新、天气预警、空气质量提醒、日出日落提醒或已配置的短时降雨信息。

## 配置顶部进度与信息

“顶部进度与信息”把进度和临时提示放在同一队列中。可以添加：

- **24 小时进度**：展示今天从 00:00 到 24:00 的进度和时段问候。
- **课时/课间进度**：根据课程表展示当前课时或课间进度。
- **下一课时**：提示下一节课程及临近程度。
- **短时降雨**：天气数据可信且进入设定时间窗时显示。
- **天气预警**：展示当前有效预警的摘要。
- **自定义文案**：例如“记得完成今日复盘”。

使用方法：

1. 从“添加信息”中选择项目。
2. 通过拖动、上移或下移调整顺序。
3. 对下一课时、短时降雨、天气预警或自定义文案选择背景进度。
4. 对下一课时或短时降雨设置显示时机。
5. 不需要时点击移出；被移出的自定义文案会保留，可稍后恢复。选择“永久删除”才会彻底删除文案。

最多启用 20 条。启用两条或更多时会自动轮播，间隔可设为 3–30 秒；提醒信息到达重要时间点时会提高优先级。鼠标悬停、键盘聚焦或页面进入后台时，轮播会暂停；点击当前信息或按 `Enter` / `Space` 可手动切换。

如果没有启用任何条目，这一块会隐藏。短时降雨数据过期、缺少可信时间或定位不可用时，不会显示确定的降雨倒计时。

## 配置事件倒计时

“设置 → 常用工作台 → 倒计时”控制的是自习页顶部的事件倒计时，与独立的“倒计时模式”不同。

可以选择：

- **高考**：按目标年份的 6 月 7 日自动计算剩余天数。
- **单事件**：填写事件名称和日期。
- **多事件**：添加高考或自定义项目，排序后按设定秒数轮播。

多事件模式下，列表顺序就是展示顺序。保存设置后，目标和顺序才会应用到自习页。

## 编辑课程表

打开“设置 → 常用工作台 → 课程表”。每个时段包含：

- 课程名称；
- 开始时间；
- 结束时间。

你可以添加、复制、删除、上移、下移或按开始时间排序。应用会检查空时间、结束早于开始和时间重叠等问题；存在红色错误时无法保存设置。

页面中的三个辅助操作含义如下：

- **恢复**：放弃本次面板内的课表草稿，重新读取上次已保存内容。
- **排序**：按开始时间重排当前草稿。
- **重置**：把当前草稿替换为应用默认课程表，仍需点击设置面板底部“保存”才会生效。

## 从 Excel 导入课程表

课程表支持 `.xlsx` 和 `.xls`：

1. 在“Excel 导入”中选择文件。
2. 查看工作表名称、成功条数和失败行提示。
3. 选择“替换当前课表”或“合并追加”。
4. 在下方修正时间冲突或无效内容。
5. 点击设置面板底部“保存”。

导入只是生成课表草稿，不会在选择文件后立即覆盖已保存课表。“合并追加”会保留当前草稿并追加导入时段，较容易产生重叠，建议应用后先点“排序”检查。

## 噪音报告与课程表的关系

启用自动弹出报告后，应用会在当前课时结束前约 1 分钟打开该课时的噪音报告。同一课时手动关闭后不会反复弹出。自动关闭时长只影响这种自动弹出的报告；从历史记录打开的报告会一直保留，直到你主动关闭或返回。

报告依赖有效监测数据。课程表本身不会开启麦克风，也不会在没有噪音数据时制造评分。

## 投屏前检查清单

- 课程时间是否与当天实际安排一致；
- 顶部信息是否过多，远距离能否看清；
- 背景与文字对比度是否足够；
- 天气城市是否正确；
- 麦克风权限是否已授权，提醒音量是否合适；
- 浏览器和系统是否已关闭自动休眠；
- 如需保留历史，是否已开启“保存监测数据”。
