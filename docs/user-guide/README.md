## 重要提醒

- 大多数设置只有点击设置面板底部的“保存”后才会生效；点击“取消”会放弃本次草稿。
- 课程表、倒计时、语录、自定义背景、噪音历史等数据默认保存在当前浏览器或桌面客户端中，不会自动同步到其他设备。
- 麦克风监测的核心指标是 `0–100` 的环境安静评分。估算 dB(A) 必须使用外部声级计校准，不能当作认证声级计读数。
- 天气、公共 IP 降级定位和在线语录依赖第三方网络服务；离线时仍可使用时钟、倒计时、秒表以及已经缓存或保存在本地的内容。
- 完整备份是明文 JSON，可能含有位置、课程安排、语录和噪音活动时间，请只保存在可信设备上。
