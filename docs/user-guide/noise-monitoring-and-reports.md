# 噪音监测与报告

## 先理解两个数值

沉浸式时钟默认使用 **环境安静评分**：

- 范围为 `0–100`；
- 分数越高，表示当前环境越安静；
- 不需要外部声级计校准；
- 用于同一设备上的日常自习提醒和时段趋势，不是法定或专业声学测量。

另一个可选指标是 **估算 dB(A)**。它只有在使用旁置声级计完成校准后才会出现，仍然不是认证声级计读数。校准只改变估算分贝，不会改变环境安静评分。

## 开始监测

1. 打开“设置 → 环境提醒 → 噪音监测 → 控制”。
2. 点击“授权并刷新”，允许浏览器或桌面客户端使用麦克风。
3. 选择“系统默认”或指定输入麦克风。
4. 开启“启用环境监测”。
5. 根据需要开启“保存监测数据”“显示实时数值”和“麦克风异常后自动隐藏”。
6. 点击设置面板底部“保存”。

返回自习页后，监测通常会经历“连接监测”“初始化中”“采集中”，积累足够有效声音数据后进入“安静”或“吵闹”状态并显示评分。

如果浏览器还没有麦克风权限，设备名称可能不可见；“授权并刷新”会先申请权限，再重新读取设备列表。所选设备暂时离线时，应用会临时使用系统默认设备，同时保留原选择，以便设备恢复后继续使用。

## 控制选项

“噪音监测 → 控制”中的选项含义：

- **启用环境监测**：关闭后释放麦克风，停止实时评分和新的历史写入。
- **保存监测数据**：保存本地特征帧和评分结果。关闭后仍可实时评分，但不会新增可重算的历史数据。
- **显示实时数值**：决定自习页是否显示当前分数或估算 dB(A)。
- **麦克风异常后自动隐藏**：默认开启。“麦克风异常”持续 5 分钟后，会关闭自习页的噪音监测显示；监测仍会继续，需要时可在“自习显示”中手动重新开启。
- **低于提醒分数播放提示音**：环境分数低于提醒线时播放声音提示。
- **提醒分数**：`40–90`，越高越严格。
- **实时主指标**：选择环境安静评分或估算 dB(A)。未校准时选择估算 dB(A)，页面会提示“需校准”。

提醒音可能比较频繁，教室投屏前建议先在现场测试音量。浏览器的自动播放限制也可能要求你先点击页面，声音才可正常播放。

## 监测状态怎么理解

| 状态                | 含义与处理                                                     |
| ------------------- | -------------------------------------------------------------- |
| 监测已关闭          | 到设置中打开“启用环境监测”                                     |
| 连接监测 / 初始化中 | 正在协调标签页或建立音频处理，稍候即可                         |
| 采集中              | 正在积累首次评分所需的有效数据                                 |
| 安静 / 吵闹         | 已有可用评分；点击状态文字可打开历史                           |
| 低于量程            | 有非零信号，但当前输入过低，检查麦克风距离或增益               |
| 信号异常            | 持续零值或疑似系统音频处理使数据不可信，检查设备与系统处理选项 |
| 信号不可用 / `--`   | 权限、设备或音频链路失败；点击状态文字重试                     |

多个标签页同时打开时，只有一个标签页实际占用麦克风，其他标签页会同步摘要。这样可以避免同一网站重复采集；如果所有标签页都停在连接状态，关闭多余标签页后重试。

## 查看历史和报告

在自习页点击噪音状态或旁边的呼吸灯，可以打开“历史记录管理”。这里会：

- 列出最近 14 天内能够组成报告的课程时段；
- 显示平均环境安静评分；
- 允许打开课程详情；
- 允许自定义报告名称、开始时间和结束时间。

报告会展示：

- 平均环境安静评分和当前提醒线；
- 达标率、有效时长和需要留意的时长；
- 评分或估算 dB(A) 趋势；
- 数据覆盖率和被排除时长；
- 整体声活动、持续声活动、声音事件频度三类实际扣分；
- 最低记录和报告数据范围说明。

报告只统计有效数据。覆盖不足时，会明确说明结论只能代表已经采集到的部分，不能代表整个时段。没有足够有效数据时，报告会显示空状态，而不是猜测一个分数。

## 自动弹出报告

在“噪音监测 → 报告”中：

- “自动弹出报告”默认开启；
- 课程结束前约 1 分钟自动打开当前课时报告；
- 同一课时手动关闭后不会重复弹出；
- 自动关闭时长可设为 1–60 分钟；
- 从历史记录打开的详情不会自动关闭。

报告数据固定保留 14 天，过期的原始特征和派生评分会一起清理。

## 校准估算 dB(A)

需要一台可靠的外部声级计：

1. 把声级计放在当前麦克风旁边，尽量让两者处于同一声场。
2. 打开“设置 → 环境提醒 → 噪音监测 → 校准”。
3. 输入声级计当前读数，范围为 `30–120 dB(A)`。
4. 点击“开始校准”，确认后保持环境稳定 10 秒。
5. 校准成功后，将实时主指标切换为“估算 dB(A)”并保存。

以下情况会导致校准拒绝或失效：

- 声场在 10 秒内波动过大；
- 信号异常；
- 系统音频处理无法确认关闭；
- 更换麦克风、采样率或处理配置。

“清除校准”只删除估算 dB(A) 参考，不影响环境安静评分、监测设置和已有评分历史。

## 本地数据与 `.icnoise`

启用“保存监测数据”后，应用在当前设备保存用于评分的特征数据，不保存可播放的原始 PCM 录音。它们可用于未来重新计算评分。

- 常规“完整备份”包含派生的噪音历史，但不包含原始特征帧。
- 原始特征需要在“系统数据 → 设置数据 → 原始监测数据”单独导出为 `.icnoise`。
- `.icnoise` 可按日期范围导出；导入前会先检查文件、重复数据和可用空间，确认后才写入，并在导入后自动重算评分。
- “清理噪音历史”会删除采集会话、原始特征、派生评分和重算状态，但保留噪音设置与 dB(A) 校准。

详情见[数据备份、隐私与重置](data-backup-privacy-and-reset.md)。

## 隐私与使用边界

- 麦克风音频在当前设备中处理；噪音历史保存的是特征和评分，不是可回放录音。
- 应用不会把环境安静评分包装成专业分贝结论。
- 系统降噪、自动增益、回声消除、麦克风质量和摆放位置都会影响结果。
- 不要把本功能用于劳动卫生、执法取证、医疗诊断或其他需要认证仪器的场景。
- 使用公共或共享设备后，记得清理噪音历史，必要时删除全部本地数据。
