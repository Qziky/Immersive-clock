# 常见问题与故障排查

## 界面与操作

### HUD 不出现，或者很快消失

点击页面空白处，或按 `Space` / `Enter`。HUD 大约 8 秒无操作后自动隐藏；焦点位于 HUD 内时不会隐藏。设置、倒计时编辑或其他弹窗打开时，页面快捷键会暂停。

### 找不到设置按钮

设置按钮位于左下角，空闲时会变得低调。移动鼠标、点击页面或使用键盘切换焦点后再查看。弹窗打开时设置按钮会暂时隐藏。

### 修改设置后没有变化

大多数设置只是草稿，必须点击设置面板底部“保存”。点击“取消”、直接刷新或关闭页面会放弃未保存内容。外观预览看起来已经变化也不代表已经保存。

### 如何重播新手指引

切换到“时钟”模式，点击左下角问号按钮。

## 时钟、倒计时与秒表

### 设置倒计时后为什么没有自动开始

“确认”只保存本次时长。关闭设置弹窗后唤出 HUD，再点击“开始”。

### 如何重新设置正在运行的倒计时

单击中央倒计时时间即可重新打开设置。新设置会停止并替换当前倒计时。

### 倒计时结束没有声音

先点击一次页面，让浏览器允许声音播放；再检查标签页静音、系统音量、输出设备和“请勿打扰”。部分移动系统在后台或静音模式下不会播放网页提示音。

### 时钟时间不准

先检查系统时间和时区。默认模式完全跟随设备；如果启用了外部校时，到“设置 → 系统数据 → 时间校准”查看最近错误，必要时切回“默认”。

## 自习与课程表

### 自习页太拥挤

到“常用工作台 → 自习显示”隐藏天气、噪音、倒计时、语录或日期，并减少“顶部进度与信息”条目。中央时间始终保留。

### 课时进度不对

检查课程表中的开始、结束时间和重叠错误，然后点击设置面板底部“保存”。如使用外部校时，也要确认当前有效时间没有被错误偏移。

### CSES YAML 导入后课表没有变化

选择文件后还要等待严格校验通过，点击“覆盖当前草稿”，确认周期锚点，最后点击设置面板底部“保存”。文件选择和预览不会立即覆盖草稿或已保存课表；存在字段路径错误时必须先修正 YAML 文件。

### 自动噪音报告没有弹出

确认已开启“噪音监测 → 报告 → 自动弹出报告”，当前时间处于课表内，且已经积累有效监测数据。报告只会在课时结束前约 1 分钟弹出；同一课时手动关闭后不会重复出现。

## 天气与定位

### 一直显示定位中或天气加载失败

检查网络和位置权限，到“环境提醒 → 定位服务”点击“刷新高精度定位”。若浏览器不再询问权限，请在地址栏站点权限或系统隐私设置中改为允许。仍失败时选择手动城市。

### 自动定位到错误城市

查看来源。如果是“公共 IP 降级定位”，VPN、代理、校园网和运营商出口会造成偏差。改用“手动城市”，搜索并从候选中选择准确结果。

### 手动城市无法保存

输入城市名后必须点击“搜索城市”，再选择一个小米城市候选。只输入文字不算完成选择。

### 隐藏天气后仍收到预警

显示开关和提醒开关独立。到“环境提醒 → 天气服务 → 提醒”关闭弹窗；如果顶部仍显示天气预警或短时降雨，到“自习显示 → 顶部进度与信息”移出对应条目。

### 天气一直是旧数据

在“天气服务 → 更新”查看上次更新、下次更新和错误，点击“刷新天气”。离线或第三方接口失败时会保留最近缓存；恢复网络后再刷新。

## 噪音监测

### 麦克风没有数据

1. 到“噪音监测 → 控制”确认“启用环境监测”已开启。
2. 点击“授权并刷新”。
3. 检查浏览器和操作系统麦克风权限。
4. 确认选择了存在的输入设备。
5. 关闭其他独占麦克风的软件后，点击自习页状态文字重试。

### 看不到麦克风设备名称

浏览器通常在授权前隐藏设备名称。点击“授权并刷新”后再打开设备列表。

### 多个页面都显示“连接监测”

同一浏览器中只有一个标签页实际采集。保留一个自习页，关闭多余标签页并等待片刻；仍无结果时刷新页面或重新授权。

### 显示“信号异常”或“低于量程”

“低于量程”表示存在非零输入但信号太低，可检查麦克风距离、静音和输入增益。“信号异常”可能是持续零输入，也可能是系统降噪、自动增益或其他音频处理导致不可信；尝试更换设备或关闭系统处理后重试。

### 为什么只显示评分，不显示分贝

浏览器麦克风没有统一的物理声压参考。需要旁置声级计进行稳定 10 秒校准，成功后才能显示估算 dB(A)。它仍不是认证声级计读数。

### 报告显示“暂无有效噪音评分”

所选时段没有足够有效覆盖，或保存历史未开启、麦克风中断、信号异常、数据已经过期清理。保持页面前台和麦克风可用，积累新的有效数据后再查看。

### 完整备份为什么没有原始监测帧

JSON 完整备份只包含派生噪音历史。原始特征需要在“设置数据 → 原始监测数据”单独导出 `.icnoise`。

## 语录

### 在线语录加载失败

检查网络并确认至少一个在线频道启用。应用会尝试其他在线来源、最近缓存和本地频道；建议始终保留一个本地频道。

### 语录中英文混合

Advice Slip 提供英文内容。一言、今日诗词和诗泉主要提供中文；关闭 Advice Slip 即可避免大部分英文句子。

### 诗泉没有按筛选显示

在“内容语录 → 语录渠道”展开诗泉的“诗词筛选”，修改朝代或体裁后点击设置面板底部“保存”。
应用会按筛选组合隔离缓存；若公网服务暂时不可用，会改用其他在线来源或本地频道。

### 导入 TXT 失败

确保文件是纯文本、每行一条、至少有一条不超过 200 字符的内容，总条数不超过 1000。导入后仍要点击“保存”。

## 安装、离线与更新

### 浏览器没有 PWA 安装按钮

确认使用 HTTPS、页面完成加载、浏览器支持安装且应用未安装。iPhone/iPad 需要从 Safari 的“分享 → 添加到主屏幕”进入。

### 离线时天气或在线语录不可用

这是正常现象。核心计时和本地内容可离线使用，但新天气、城市搜索、在线语录、网络校时和反馈页面需要网络。

### PWA 一直显示旧版本

先打开“设置 → 系统数据 → 应用更新”点击“检查更新”。若显示“资源准备中”，保持联网并重试；
若点击“立即更新”后仍是旧版本，再关闭所有相关标签页和 PWA 窗口后重新打开。最后才清理“临时
缓存”；不要直接清除全部站点数据，除非已经创建备份。

### 桌面更新下载失败

在“应用更新”中重试；仍失败时打开发布页手动下载。便携版、deb 和 rpm 本来就不会自替换。
如果系统提示来源或签名风险，请先核对文件来自项目 GitHub Release 和 `SHA256SUMS.txt`。

### Android 点击更新没有打开 APK

应用会自动回退到 GitHub Release 页面。若仍无反应，请检查系统是否允许应用打开外部链接，再从
Release 手动下载正式签名 APK；不要安装来源不明或签名不同的包。

### macOS 有桌面安装包吗

当前没有对外发布的 macOS 安装包，请使用网页版或安装为 PWA。Windows 和 Linux 构建请查看 GitHub Releases。

## 数据与隐私

### 换浏览器或设备后设置不见了

应用没有账号同步。回到旧设备创建 JSON 备份，在新设备从“系统数据 → 设置数据”恢复；麦克风和位置权限需要重新授权。

### 自定义背景和字体会上传吗

应用把它们保存到当前设备的本地资源库，不会作为天气或语录请求上传。完整或“设置与资源”备份会把资源写入你主动下载的明文 JSON。具体部署还可能启用网页使用统计，请不要在共享设备中导入敏感素材。

### “恢复默认设置”会删除什么

它重置显示、提醒、天气、噪音和外观等偏好，但保留课程表、事件倒计时、语录内容、历史、自定义字体和背景。

### 如何彻底清空

到“系统数据 → 设置数据 → 危险操作”，选择“删除全部本地数据”。这会永久删除本应用登记的设置、记录、资源和缓存，操作前先备份。

### 备份恢复失败

查看预检提示。常见原因包括文件损坏、由更高版本应用生成、不支持的旧噪音历史、资源内容不安全或手工修改破坏格式。保留原文件，并尽量在相同或更新的兼容版本中恢复。

如果问题仍然存在，可点击主界面右下角版本号，在公告窗口中选择“意见反馈”，并附上应用版本、浏览器/系统、复现步骤和“系统数据 → 错误与调试”中的相关摘要。不要公开上传含位置、课程或备份内容的敏感文件。
