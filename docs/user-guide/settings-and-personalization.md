# 设置与个性化

## 设置导航

当前设置面板分为五个一级分组：

| 分组       | 子页面                                   | 主要用途                       |
| ---------- | ---------------------------------------- | ------------------------------ |
| 常用工作台 | 启动页面、自习显示、倒计时、课程表       | 决定主界面展示什么             |
| 视觉外观   | 整体样式、时间显示、语录、顶部信息栏     | 调整字体、背景、颜色和组件样式 |
| 环境提醒   | 噪音监测、天气服务、定位服务             | 管理权限、环境数据和提醒       |
| 内容语录   | 刷新策略、显示效果、语录渠道             | 管理语录内容与播放方式         |
| 系统数据   | 时间校准、项目信息、设置数据、错误与调试 | 校时、备份、重置和诊断         |

窄屏设备会先显示一级分组，再展开相应子页面；桌面宽屏通常会同时显示完整导航。

## 保存与取消

设置面板采用“先预览、后保存”：

- 修改普通设置后，点击底部“保存”统一生效。
- 点击“取消”会丢弃未保存草稿。
- 外观调整会立即显示在主界面预览中，但未点击“保存”前不会持久化。
- 从备份恢复、分类清理、恢复默认和删除全部数据是立即执行操作，通常会提示确认，并可能刷新页面。

切换子页面不会自动保存。关闭浏览器、刷新页面或执行数据恢复前，应先确认是否需要保存当前草稿。

## 整体样式

“视觉外观 → 整体样式”控制所有页面默认使用的资源：

- **主显示字体**：时钟、倒计时和秒表等大数字。
- **信息字体**：日期、天气和辅助文字。
- **整体背景**：在“静态背景”和“动态背景”之间选择。静态背景保留现有预设、纯色和图片；动态背景提供粒子效果、音乐响应和自定义视频。
- **字体资源**：可导入 `.ttf`、`.otf`、`.woff`、`.woff2`。
- **资源清单**：查看、预览、应用或删除当前未使用的背景和字体。

本地图片、字体和视频保存在当前设备，不会因为选择文件就自动上传。正在被外观设置引用的资源不能直接删除；先把相关组件切换到其他字体或背景并保存，再清理资源。

## 分别调整页面和组件

“时间显示”可以分别选择：时钟、倒计时、秒表、自习时间。每个对象都有自己的预览和可调整内容。

“顶部信息栏”可以分别选择：栏体、天气、噪音监测、顶部进度与信息、事件倒计时。

常见可调项目包括颜色、透明度、字体、字重；字间距、文字阴影、边框、圆角和背景模糊等低频选项会放在更详细的设置中。出现“对比度较低”提示时，建议提高文字和背景之间的明暗差异，尤其是用于远距离投屏时。

页面背景支持以下层级：

- 整体背景作为默认值；
- 时钟、倒计时、秒表、自习和考试页面可以单独选择“跟随整体”，或覆盖为静态/动态背景；
- 单个文字或组件样式可继续覆盖整体样式。

恢复操作也遵循层级：可以恢复当前对象、当前组件、当前状态、整体样式，或重置全部外观。恢复只修改草稿，仍需点击“保存”。

### 动态背景

选择动态背景后，可在三类效果间切换；同一次设置编辑会保留每类最近的选项：

- **粒子效果**：星空或连线粒子，可调整颜色、密度、速度和暗化程度。
- **音乐响应**：频谱或波形，可调整颜色和灵敏度。点击“开始监听”后选择麦克风；支持电脑音频的安全浏览器可选择共享带音轨的标签页，Windows 桌面版也提供系统回环音频。Android 不提供电脑音频来源。可随时停止监听；离开音乐背景或切换音源后，需要重新开始。
- **自定义视频**：导入本地 MP4/WebM（每个最大 200MB），或填写 HTTP(S) 视频直链。可选铺满/完整显示、暗化、是否允许开启原声和音量。视频默认静音；主屏需手动点击“开启视频声音”，设置预览始终静音。

动态背景默认暗化 35%，以保证中央时间清晰。刷新后音乐监听不会自动恢复，需要重新点击开始；视频会继续静音播放。

## 显示秒数

在“视觉外观 → 时间显示”中：

- 使用“中央时间大小”滑块，以 75%–125% 调整四个时间页面的中央数字；
- 选择“时钟”，可单独关闭时钟页秒数；
- 选择“自习时间”，可单独关闭自习页秒数。

倒计时和秒表始终保留秒级显示，不受这两个开关影响。

## 启动页面

“常用工作台 → 启动页面”可选择下次启动或刷新默认进入时钟、倒计时、秒表或自习。当前正在打开的页面不会因为选择选项而立即切换。

同一页面还提供“防止屏幕自动关闭”开关。该开关默认关闭；开启并保存后，时钟、倒计时、秒表和自习模式在应用位于前台时都会尝试保持屏幕常亮。应用最小化、切到后台或关闭后会立即允许系统正常休眠。

网页/PWA 需要浏览器支持 Screen Wake Lock，并通常需要通过 HTTPS 或本机开发地址访问。Electron 和 Android 安装版使用各自的系统能力。若浏览器、系统策略或节电状态暂时不允许常亮，设置会继续保留并显示“当前环境暂不可用”，应用返回前台后会再次尝试。屏幕常亮会增加耗电，移动设备长时间使用时建议连接电源。

## 时间校准

默认情况下，应用跟随设备系统时间。只有明确知道自己需要修正时间时，才建议打开“系统数据 → 时间校准”。

可选来源：

- **默认**：完全使用本机时间。
- **HTTP Date**：读取指定网页响应中的服务器时间。
- **时间 API**：读取兼容的时间接口。
- **NTP（桌面端）**：Electron 桌面版可填写 NTP 主机和端口；网页/PWA 不提供该选项。

启用外部来源后，还可以填写手动偏移、设置自动校时间隔或点击“立即校时”。网络、防火墙、跨域限制或时间服务格式不兼容都可能导致失败；失败时可切回“默认”。

## 减少动态效果与可读性

应用会尊重系统的“减少动态效果”偏好。启用后，语录等内容会直接显示或减少过渡。若用于长时间投屏，还建议：

- 避免过低透明度；
- 使用简单背景并确保文字对比明显；
- 根据观看距离放大主要数字；
- 在窄屏上减少顶部信息数量；
- 不要用颜色作为唯一状态提示。
