# 宣传资料库

本目录集中管理沉浸式时钟的对外介绍、品牌表达、渠道文案和素材规范。目标是让官网、README、发布页、社交平台与社区介绍说同一种话，并且只宣传当前真实存在的能力。

产品定位以[产品知识库](../product/README.md)为准；功能发生变化时，先更新产品或使用文档，再更新宣传内容。运行时公告与更新日志仍维护在 `public/docs/`，本目录只提供模板和可复用表达，不复制线上正文。

## 文案

- [产品简介](copy/product-introduction.md)：一句话、短版、标准版和长版介绍。
- [品牌表达](copy/brand-messaging.md)：名称、语气、信息顺序和禁用说法。
- [功能亮点](copy/feature-highlights.md)：可组合的功能卡片与必要限定。
- [渠道文案](copy/channel-copy.md)：README、官网、社交平台、社区和发布页范本。
- [发布说明模板](copy/release-notes-template.md)：版本发布时的结构、检查项和示例。

## 素材

- [素材清单](assets/asset-inventory.md)：现有主视觉、图标、分享图和社群图片的权威索引。
- [截图规范](assets/screenshot-guidelines.md)：新截图的内容预设、尺寸、命名和验收规则。

## 社区

- [社区与生态](community-and-ecosystem.md)：反馈入口、友情链接和合作边界。

## 使用原则

- 先讲用户价值，再讲功能，最后才讲技术实现。
- 不把“功能很多”作为核心卖点；优先突出清晰、低打扰和学习场景。
- 不承诺所有功能完全离线，不承诺跨设备同步或 macOS 原生安装包。
- 不把环境安静评分称为专业分贝测量；估算 dB(A) 必须带上校准条件。
- 截图、平台列表和版本信息发布前必须按当前构建重新核对。
- 未上线能力不得用将来时包装成已可用功能。
