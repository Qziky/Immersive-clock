# 沉浸式时钟 v4.0.3

发布日期：2026 年 8 月 14 日

v4.0.3 聚焦于让重复使用的倒计时目标更容易设置。现在可以保存一个自定义倒计时时长，并在后续使用中通过快速设置直接复用；现有本地设置会自动迁移并继续保留。

## 本次变化

### 倒计时快速设置

- 倒计时面板新增“自定义”快速设置入口，可保存当前小时、分钟和秒数。
- 保存后会显示为自定义常用时长，重新打开面板即可快速复用。
- 手动调整倒计时会自动切换到自定义时长；关闭面板会放弃未确认的草稿。

### 数据与测试

- 应用设置升级至 schema v19，旧设置会自动迁移；已有课程、资源和其他偏好不受影响。
- 补充倒计时组件、设置迁移和端到端流程测试。

## 更新方法

- Web/PWA：用 Web ZIP 内容替换自托管站点；新版资源被浏览器发现后会自动切换和刷新。
- Windows 安装版：退出旧版本后运行新安装程序，或等待已下载的自动更新在正常退出后安装。便携版请下载新附件并替换到新目录。
- Linux：AppImage 可接受后台更新；deb、rpm 请按原包格式安装新版。替换 AppImage 后如无法启动，请重新授予执行权限。
- Android：从本 Release 下载 APK 后覆盖安装。后续版本必须继续使用同一发布证书才能直接升级。
- Docker：固定生产环境到 `4.0.3`，或按需使用 `4.0`、`4`、`latest`；部署后检查健康端点和天气代理。

建议在升级、覆盖安装或清理站点数据前，先从“设置 → 系统数据 → 设置数据”导出完整 JSON 备份。现有本地设置、课程和资源会保留在各自客户端；Web、桌面客户端和 Android WebView 的数据彼此独立，不会自动云同步。
