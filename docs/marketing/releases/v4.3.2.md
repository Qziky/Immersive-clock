# 沉浸式时钟 v4.3.2

发布日期：2026-11-21

本次修复 Web/PWA 显示有新版本、却没有可用更新操作的问题。更新资源准备好后，你可以在计时结束再刷新。

## 本次变化

- “设置 → 系统数据 → 应用更新”会区分发现新版、准备资源、就绪和切换失败。资源就绪后点击“刷新并更新”，失败可重试。
- 确认新版接管后，只刷新发起更新的空闲窗口。倒计时或秒表运行中、暂停且已有进度，或正在编辑倒计时时不会刷新；其他已加载新版的窗口不会跟着刷新。
- 修复部分静态页面可能带着构建时的弹窗状态，导致页面无法交互的问题。更新不清除已保存的设置和历史数据。

## 更新方法

- Web/PWA：自托管站点先部署新版 Web ZIP，并继续提供 HTTPS、SPA fallback 与天气同源代理。如果旧版只有“检查更新”且一直未切换，请等计时结束，关闭此站点的所有标签页和已安装网页应用窗口，再重新打开。不必清除网站数据。新的更新操作和计时保护在页面已载入 v4.3.2 后生效。
- Windows：安装版可使用应用更新或运行新安装程序；便携版请下载新版并替换到新目录。
- Linux：AppImage 可使用应用更新；deb、rpm 按原包格式安装。
- Android：下载 APK 覆盖安装，后续版本仍需使用相同发布证书。
- Docker：可固定到 `4.3.2`，或按需使用 `4.3`、`4`、`latest`，部署后检查健康端点和天气代理。

建议升级前从“设置 → 系统数据 → 设置数据”导出完整 JSON 备份，各客户端数据分别保存在本地。
