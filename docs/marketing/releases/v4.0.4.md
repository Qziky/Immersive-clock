发布日期：2026 年 8 月 19 日

## 本次变化

### 课程表与自习

- 课程表支持 `rest_count: 1` 的单休周期兼容扩展；导入预览、周期编辑、运行时课程解析和导出 YAML 均可保留该配置。
- 使用单休配置时会显示兼容提示：本应用可正常处理，但部分严格 CSES v2 工具可能不接受此扩展。

### 噪音监测与更新

- 新增“麦克风异常后自动隐藏”开关，默认开启。麦克风异常连续五分钟时，仅关闭自习页噪音监测显示，不停止采集或历史记录。
- 应用更新页新增“检查更新”按钮，可立即查询当前平台的稳定版更新。
- 应用设置升级至 schema v20，旧设置会自动补齐新增的噪音显示偏好。

### 文档、设计与测试

- 更新课表、噪音监测、离线更新和用户指南，明确单休兼容性与异常自动隐藏行为。
- 新增“时间空间”界面设计草图，作为后续场景化时间体验的设计参考。
- 补充课程表、噪音监测、设置迁移、手动更新检查和端到端持久化测试。

## 更新方法

- Web/PWA：用 Web ZIP 内容替换自托管站点；新版资源被浏览器发现后会自动切换和刷新。
- Windows 安装版：退出旧版本后运行新安装程序，或等待已下载的自动更新在正常退出后安装。便携版请下载新附件并替换到新目录。
- Linux：AppImage 可接受后台更新；deb、rpm 请按原包格式安装新版。替换 AppImage 后如无法启动，请重新授予执行权限。
- Android：从本 Release 下载 APK 后覆盖安装。后续版本必须继续使用同一发布证书才能直接升级。
- Docker：固定生产环境到 `4.0.4`，或按需使用 `4.0`、`4`、`latest`；部署后检查健康端点和天气代理。

建议在导入课表、升级、覆盖安装或清理站点数据前，先从“设置 → 系统数据 → 设置数据”导出完整 JSON 备份。现有本地设置、课程和资源会保留在各自客户端；Web、桌面客户端和 Android WebView 的数据彼此独立，不会自动云同步。
