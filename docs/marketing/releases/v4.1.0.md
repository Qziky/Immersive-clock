发布日期：2026-10-06

## 本次变化

### 时间与考试模式

- 新增考试模式，可使用常见考试预设或自定义考试信息与科目安排，并支持考试进行、暂停、恢复和结束提醒。
- 新增中央时间大小调节，并应用于时钟、倒计时、秒表、自习和考试界面。

### 动态背景与个性化

- 动态背景新增粒子效果、音乐响应和本地视频；可调整展示方式、颜色与暗度。
- 个性化数据备份与恢复支持背景媒体资源，改善较大视频文件的处理。
- 语录渠道设置和显示效果得到扩展，频道编辑与响应式布局更稳定。

### 安全、兼容与验证

- Electron 电脑音频采集在开始前要求用户明确选择共享屏幕；取消或无效请求不会授予采集权限。
- 优化时间舞台、菜单、考试布局和设置页在桌面及窄屏设备上的适配。
- 补充考试、动态背景、数据备份与语录流程的自动化和真机验收覆盖。

## 更新方法

- Web/PWA：用 Web ZIP 内容替换自托管站点；新版资源被浏览器发现后会自动切换和刷新。
- Windows 安装版：退出旧版本后运行新安装程序，或等待已下载的自动更新在正常退出后安装。便携版请下载新附件并替换到新目录。
- Linux：AppImage 可接受后台更新；deb、rpm 请按原包格式安装新版。替换 AppImage 后如无法启动，请重新授予执行权限。
- Android：从本 Release 下载 APK 后覆盖安装。后续版本必须继续使用同一发布证书才能直接升级。
- Docker：固定生产环境到 `4.1.0`，或按需使用 `4.1`、`4`、`latest`；部署后检查健康端点和天气代理。

建议在升级或导入数据前，从“设置 → 系统数据 → 设置数据”导出完整 JSON 备份。各客户端的数据分别保存在本地，不会自动云同步。
