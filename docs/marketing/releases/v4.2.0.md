# 沉浸式时钟 v4.2.0

发布日期：2026-10-10

v4.2.0 新增可选 OLED 防烧屏闲置屏保。开启后，时钟、倒计时、秒表或自习页面在无人操作一段时间后会显示纯黑背景与缓慢移动的低亮度时间；操作会立即恢复原界面。屏保默认关闭，考试模式不受影响。

屏保会沿用“中央时间大小”设置，保持与原界面一致的字号。倒计时进入最后 10 秒或出现重要提醒时会自动唤醒。此功能用于降低长时间显示静态画面的烧屏风险，实际效果取决于 OLED 设备及其使用情况。

## 本次变化

### OLED 防烧屏闲置屏保

- 在“设置 → 视觉外观 → 整体样式 → OLED 防烧屏”中开启功能，并设置闲置时长（1、3、5 或 10 分钟）和屏保亮度（20%–80%）。默认关闭、闲置 5 分钟、亮度 40%。
- 闲置后显示纯黑背景和缓慢移动的模式时间；时间字号与中央时间大小设置保持一致。
- 鼠标、触控、滚动或键盘操作会恢复原界面。倒计时最后 10 秒、结束或重要提醒出现时会自动唤醒；考试模式除外。
- 设置弹窗、菜单和新手引导期间不会进入屏保。底层计时器继续运行，避免屏保中断计时和提醒。

### 设置兼容与验证

- 应用设置升级至 schema v23，旧配置自动迁移，且不会默认开启屏保。
- 补充设置保存、迁移、计时快照与屏保自动化流程覆盖。

## 更新方法

- Web/PWA：用 Web ZIP 内容替换自托管站点；新版资源被浏览器发现后会自动切换和刷新。
- Windows 安装版：退出旧版本后运行新安装程序，或等待已下载的自动更新在正常退出后安装。便携版请下载新附件并替换到新目录。
- Linux：AppImage 可接受后台更新；deb、rpm 请按原包格式安装新版。替换 AppImage 后如无法启动，请重新授予执行权限。
- Android：从本 Release 下载 APK 后覆盖安装。后续版本必须继续使用同一发布证书才能直接升级。
- Docker：固定生产环境到 `4.2.0`，或按需使用 `4.2`、`4`、`latest`；部署后检查健康端点和天气代理。

建议在升级或导入数据前，从“设置 → 系统数据 → 设置数据”导出完整 JSON 备份。各客户端的数据分别保存在本地，不会自动云同步。
