# 沉浸式时钟 v4.3.1

发布日期：2026-11-21

常用的倒计时时长不必每次重设。可以直接输入时分秒，把 2 小时 30 分钟、3 小时等时长加入常用列表。

## 本次变化

- 时间输入区改为一行等宽数字，点数字即可编辑；手机会弹出数字键盘，仍可用加减按钮微调。
- 常用列表可保存多个不同的时长、按需移除，确认才保存。普通自定义设置仍记住上次时长，不会覆盖常用列表。
- 空闲时点选已保存的时长只更新表盘，仍需手动开始。运行中或暂停且已有进度时，点选只会填入编辑区，确认替换后才舍弃原有进度。
- 常用时长随设置备份，可以在恢复默认偏好时保留；旧版“自定义”时长仍可复用。

## 更新方法

- Web/PWA：用 Web ZIP 替换自托管站点，提供 HTTPS、SPA fallback 与天气同源代理；浏览器发现新版资源后会自动切换并刷新。
- Windows：安装版可使用应用更新或运行新安装程序；便携版请下载新版并替换到新目录。
- Linux：AppImage 可使用应用更新；deb、rpm 按原包格式安装。
- Android：下载 APK 覆盖安装，后续版本仍需使用相同发布证书。
- Docker：可固定到 `4.3.1`，或按需使用 `4.3`、`4`、`latest`，部署后检查健康端点和天气代理。

建议升级前从“设置 → 系统数据 → 设置数据”导出完整 JSON 备份，各客户端数据分别保存在本地。
