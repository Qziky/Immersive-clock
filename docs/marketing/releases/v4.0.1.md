# 沉浸式时钟 v4.0.1

发布日期：2026 年 8 月 6 日

v4.0.1 是一次面向日常使用的稳定性更新。它集中修复 QQ 浏览器的颜色兼容问题，以及部分设备上时间区域的布局和字号异常；同时重新安排启动加载顺序，补充公开的隐私与使用协议，并将默认背景调整为更适合长时间展示的深灰色。

## 本次变化

### 浏览器与显示

- 修复 QQ 浏览器部分场景下颜色显示不正确的问题，并为样式表加载前的页面提供深色兜底。
- 修复部分设备上时间区域的布局与字号问题，提升时钟、倒计时、秒表和自习时间在不同屏幕尺寸下的可读性。
- 将当前页面背景的默认值改为深灰色，减少全屏展示时的突兀感。

### 启动体验

- 调整启动和资源预加载的先后顺序：当前页面优先可用，非关键资源改为延后加载。
- 设置面板和模式组件按需预加载，减少首次进入和模式切换时的等待感。

### 隐私与说明

- 新增《用户使用协议》和《隐私政策》。首次使用本版本时需阅读并确认；之后可在“设置 → 关于”随时查看。
- 重新编写应用内公告和更新日志，以更清晰、贴近日常使用的方式说明产品变化与操作提示。

## 更新方法

- Web/PWA：用 Web ZIP 内容替换自托管站点，确认 Service Worker 已取得新版本；如仍显示旧页面，请关闭旧标签页后重新打开。
- Windows 安装版：退出旧版本后运行新安装程序。便携版请解压或替换到新目录。
- Linux：退出旧版本后按原包格式安装新版，或替换 AppImage 并重新授予执行权限。
- Android：从本 Release 下载 APK 后覆盖安装。后续版本必须继续使用同一发布证书才能直接升级。
- Docker：固定生产环境到 `4.0.1`，或按需使用 `4.0`、`4`、`latest`；部署后检查健康端点和天气代理。

现有本地设置、课程和资源会继续保存在各自客户端中；Web、桌面客户端和 Android WebView 的数据彼此独立，不会自动云同步。首次使用新版时，请按界面提示阅读《用户使用协议》和《隐私政策》。
