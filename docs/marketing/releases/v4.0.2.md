发布日期：2026 年 8 月 9 日

v4.0.2 聚焦于更好地安排学习节奏和让各平台更新更可预期：课程表现在支持可交换的
CSES YAML 格式，倒计时提供常用考试目标，语录可按朝代和体裁获取诗词；同时补齐了
Web、桌面端和 Android 的稳定版更新通道。

## 本次变化

### 课程表与倒计时

- 课程表可严格导入和导出 CSES v2 YAML。导入会在覆盖编辑草稿前检查周期、科目引用、时间格式和重叠，便于与支持该格式的工具交换课表。
- 课程表设置升级至 schema v18。已有旧课程表会在首次启动时自动迁移；新版默认模板、跨日课程和课程关联的噪音历史匹配更准确。
- 倒计时新增高考、中考、考研和考公快捷目标。创建后仍可修改名称、日期和展示设置。

### 语录与内容

- 新增“诗泉”在线诗词渠道，可按朝代与体裁筛选。不同筛选组合各自使用缓存；服务不可用时会继续尝试其他已启用渠道或本地内容。
- 更新隐私说明，明确在线诗词渠道、用户体验改进计划和本地数据的处理边界。分析服务默认不会因页面遮罩而获得额外的隐私保证，请勿输入不必要的敏感信息。

### 更新体验

- 新增“设置 → 系统数据 → 应用更新”，用于查看当前版本、更新状态和自动检查偏好。
- Web/PWA 发现新版 Service Worker 后会自动切换资源并刷新，重复事件会合并处理。
- Windows NSIS 安装版和 Linux AppImage 可在后台下载稳定更新，正常退出后自动安装。Windows 便携版、Linux deb/rpm 与 Android 不会自替换，会提供下载 APK、安装包或 Release 页面的入口。

### 其他改进与修复

- 优化噪音监测的状态提示及设置页的实时订阅，减少不必要的采集占用。
- 修复课程表关联的历史噪音记录在包含秒数或周期课程时可能无法正确归属的问题。
- 修复更新事件重复到达时可能触发多次刷新或重复提示的问题。

## 更新方法

- Web/PWA：用 Web ZIP 内容替换自托管站点；新版资源被浏览器发现后会自动切换和刷新。若仍显示旧页面，请关闭所有沉浸式时钟标签页或 PWA 窗口后重新打开。
- Windows 安装版：退出旧版本后运行新安装程序，或等待已下载的自动更新在正常退出后安装。便携版请下载新附件并替换到新目录。
- Linux：AppImage 可接受后台更新；deb、rpm 请按原包格式安装新版。替换 AppImage 后如无法启动，请重新授予执行权限。
- Android：从本 Release 下载 APK 后覆盖安装。后续版本必须继续使用同一发布证书才能直接升级。
- Docker：固定生产环境到 `4.0.2`，或按需使用 `4.0`、`4`、`latest`；部署后检查健康端点和天气代理。

建议在导入课表、覆盖安装或清理站点数据前，先从“设置 → 系统数据 → 设置数据”导出完整 JSON 备份。现有本地设置、课程和资源会保留在各自客户端；Web、桌面客户端和 Android WebView 的数据彼此独立，不会自动云同步。
