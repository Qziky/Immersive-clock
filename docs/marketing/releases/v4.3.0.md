# 沉浸式时钟 v4.3.0

发布日期：2026-11-04

v4.3.0 新增可自定义的计时快捷键与双按重置，并修复 Android 上按钮与键盘的全屏状态同步。

## 本次变化

- 默认空格开始、暂停或继续当前页面的倒计时与秒表；倒计时未设置时长时打开时长设置。
- 倒计时重置需要在两秒内松开并再次按 R；长按只算一次，切换页面、打开弹窗或失焦会取消确认。
- 默认 F 切换全屏、Esc 退出全屏、Enter 唤出控制栏，控制栏显示当前绑定。
- 在“设置 → 常用工作台 → 快捷键”中自定义字母、数字或空格绑定，支持冲突提示、明确替换、清除和恢复默认；保存后持久化，取消会丢弃草稿。
- 输入框、已聚焦控件、弹窗、菜单和中文输入期间保留原有按键行为。
- Android 的按钮、快捷键和考试模式共享全屏状态，切换页面后仍可正确退出全屏。

## 更新方法

- Web/PWA：用 Web ZIP 替换自托管站点，提供 HTTPS、SPA fallback 与天气同源代理；浏览器发现新版资源后会自动切换并刷新。
- Windows：安装版可使用应用更新或运行新安装程序；便携版请下载新版并替换到新目录。
- Linux：AppImage 可使用应用更新；deb、rpm 按原包格式安装。
- Android：下载 APK 覆盖安装，后续版本仍需使用相同发布证书。
- Docker：可固定到 `4.3.0`，或按需使用 `4.3`、`4`、`latest`，部署后检查健康端点和天气代理。

建议升级前从“设置 → 系统数据 → 设置数据”导出完整 JSON 备份，各客户端数据分别保存在本地。
