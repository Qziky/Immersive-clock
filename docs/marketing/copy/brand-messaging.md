# 品牌表达

## 表达目标

让用户感到这是一个安静、可靠、认真对待学习场景的工具，而不是一组追逐参数和噱头的功能集合。

## 信息顺序

对外介绍默认按以下顺序组织：

1. **场景**：校园投屏、自习空间和个人专注。
2. **核心价值**：清晰的大字时间、低打扰、长时间展示。
3. **关键能力**：四种模式，以及可选的课程、天气、噪音和语录。
4. **使用方式**：Web、PWA、Windows/Linux 桌面构建。
5. **数据边界**：本地优先，网络能力与权限按需使用。

技术栈、采样频率、缓存架构和算法名不应占据面向普通用户文案的开头。

## 语气

- 使用简洁、平静、具体的陈述句。
- 多说用户能完成什么，少说产品“领先”“颠覆”或“赋能”。
- 可以有温度，但不使用备考焦虑、排名压力或失败恐惧推动使用。
- 对权限和限制直接说明，不用小字掩盖前提。
- 描述开源社区时保持友好，不暗示未经确认的官方合作关系。

## 推荐词汇

| 想表达       | 推荐说法                                 |
| ------------ | ---------------------------------------- |
| 产品类型     | 全屏时间看板、校园自习时钟、专注辅助工具 |
| 核心体验     | 清晰、低打扰、沉浸、可定制、适合长期展示 |
| 数据策略     | 本地优先、无需账户即可使用核心功能       |
| 噪音默认指标 | 环境安静评分、相对环境趋势               |
| 校准后的读数 | 估算 dB(A)、外部参考校准后可用           |
| 离线能力     | PWA 可缓存基础资源；网络功能可能需要连接 |
| 桌面支持     | Windows/Linux 桌面构建                   |
| 天气状态     | 天气展示、降雨与气象提醒、外部天气数据   |

## 需要限定条件的说法

### “离线使用”

可以说基础时间功能和已缓存的应用资源可离线使用；必须同时说明天气、在线语录、外部校时和反馈需要网络。

### “分贝”

只有在同一句或紧邻位置说明“经外部参考校准”“估算 dB(A)”时才可使用。未校准状态只宣传环境安静评分。

### “隐私”

可以说无需账户、核心用户数据本地优先、当前噪音链路不上传麦克风音频。不能替所有部署实例承诺“零收集”，因为天气、语录、反馈和可选分析存在外部数据流。

### “桌面版”

应以实际发布附件为准。当前构建配置支持 Windows 和 Linux；macOS 只宣传 Web/PWA 使用方式。

## 禁用或避免的说法

- “专业级分贝仪”“实验室精度”“绝对准确”。
- “完全离线”“永不联网”“零数据收集”。
- “AI 智能降噪”或“AI 专注分析”，当前产品没有这类能力。
- “全平台原生应用”“原生 macOS 客户端”。
- “永久免费”“永不收费”等无法由当前版本永久保证的承诺。
- “提升成绩”“保证专注”“治疗注意力问题”等结果性或健康声明。
- “官方预警替代品”“专业气象决策”。
- “自动云同步”“多人协作”，当前产品没有账户与云工作区。

## 名称与格式

- 第一次出现使用“沉浸式时钟（Immersive Clock）”，后文可简称“沉浸式时钟”。
- 英文品牌名使用标题式大小写，不写成 `immersive clock`。
- 标语完整写作“让时间管理更优雅，让学习更专注。”，不随意改写为更强的结果承诺。
- 模式名称统一为“时钟、倒计时、秒表、自习”。
- PWA 首次出现时可写“可安装网页应用（PWA）”，后文使用 PWA。

## 示例

推荐：

> 打开即可使用的全屏时间看板，让教室、自习室和个人桌面的时间信息更清晰。

不推荐：

> 下一代 AI 时间管理神器，用专业级监测全面提升学习效率。
