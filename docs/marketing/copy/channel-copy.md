## GitHub README 开场

> 沉浸式时钟（Immersive Clock）是一款为校园投屏、自习空间和个人专注设计的全屏时间看板。它提供时钟、倒计时、秒表与自习模式，并可按需展示课程、天气、环境安静评分和语录。打开网页即可使用，也可安装为 PWA。
