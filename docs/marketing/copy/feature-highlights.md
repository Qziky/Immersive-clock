# 功能亮点

本页提供可组合的宣传模块。一次传播通常选择 3–5 个与渠道最相关的亮点，不要把全部功能堆成清单。

## 大字时间与四种模式

**标题：** 一块屏幕，四种时间方式

**短文案：** 在时钟、倒计时、秒表和自习模式之间快速切换，从日常看时间到一次专注任务都能直接开始。

**可验证能力：** 独立模式路径、HUD 模式切换、倒计时控制、秒表控制。

## 为教室与自习空间设计

**标题：** 远处看得清，长时间也耐看

**短文案：** 大字时间保持主角，课程、目标、天气和环境信息按需出现，适合教室投屏、晚自习与自习室看板。

**表达边界：** “适合”不等于数字标牌集中管理；项目不提供远程设备编组。

## 低打扰 HUD

**标题：** 需要时出现，其余时间退场

**短文案：** 点击页面或使用键盘即可唤出控制栏，无操作后自动隐藏，把注意力还给时间和当前任务。

**可验证能力：** 鼠标、触摸与键盘唤出；焦点在控件内时不会强制隐藏。

## 自习信息看板

**标题：** 把学习节奏放到同一块屏幕

**短文案：** 自由组合当前时间、日期、课程进度、多个目标日期、天气、语录和环境状态，并按场景关闭不需要的内容。

**表达边界：** 这是轻量信息看板，不是任务管理或多人日程系统。

## 天气与定位

**标题：** 在学习中看见真正需要的天气信息

**短文案：** 支持自动定位或手动城市，展示当前天气，并可开启降雨、气象预警、空气质量和日出日落相关提醒。

**表达边界：** 数据依赖网络和外部天气服务，不能替代官方预警渠道。

## 环境安静评分

**标题：** 看见环境变化，而不是制造虚假精确

**短文案：** 经麦克风授权后，在本地提取短时声音特征，展示环境安静评分、实时趋势和历史报告；完成外部参考校准后可显示估算 dB(A)。

**必须保留：** “外部参考校准”“估算”以及非专业仪器边界。

## 多渠道语录

**标题：** 给长时间展示留一点呼吸

**短文案：** 组合本地内容和多个在线语录渠道，自定义分类、权重、刷新节奏与出现动画，在线服务暂时不可用时仍可使用本地内容。

## 个性化外观

**标题：** 让时间适合屏幕，也适合空间

**短文案：** 调整字体、颜色、透明度和背景，导入本地图片与字体，并可针对不同模式和自习组件进一步微调。

**表达边界：** 用户导入资源由用户自行确认版权与使用授权。

## 本地数据管理

**标题：** 数据留在手边，也能带走

**短文案：** 无需账户即可使用核心功能，设置、课程、外观资源和监测历史优先保存在当前设备，并提供备份、恢复、清理与重置工具。

**表达边界：** 不宣传自动云同步；备份文件为明文，需要用户妥善保管。

## Web、PWA 与桌面构建

**标题：** 打开网页即可开始，也可以安装使用

**短文案：** 直接使用 Web 版，或安装为 PWA；项目同时提供 Windows 和 Linux 桌面构建能力。

**表达边界：** PWA 的安装和离线表现受浏览器支持影响；桌面附件以实际发布页为准。
