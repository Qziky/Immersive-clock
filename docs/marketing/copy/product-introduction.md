# 产品简介

以下文案按长度选用。除版本发布稿外，不建议写入具体版本号或依赖版本，以免内容快速过期。

## 产品名称

- 中文：沉浸式时钟
- 英文：Immersive Clock
- 标准标语：让时间管理更优雅，让学习更专注。

## 一句话版

一款为校园投屏、自习空间和个人专注设计的全屏时间看板。

## 极短版

沉浸式时钟把时钟、倒计时、秒表与自习信息放进一块安静、清晰、可定制的全屏界面。

## 短版

沉浸式时钟是一款面向校园投屏、自习空间和个人专注场景的全屏时间看板，提供时钟、倒计时、秒表与自习模式，并可按需展示课程、天气、环境安静评分和语录。无需账户即可使用核心功能，支持 Web、PWA 以及 Windows/Linux 桌面版本。

## 标准版

沉浸式时钟（Immersive Clock）是一款为校园投屏、自习空间和个人专注设计的全屏时间看板。它以清晰的大字时间为核心，提供时钟、倒计时、秒表和自习四种模式；在自习模式中，还可以按需组合课程进度、目标日期、天气提醒、环境安静评分与语录。

应用强调低打扰和本地优先：控制栏在不使用时自动退场，设置、课程、外观资源和监测历史优先保存在当前设备。用户可以直接使用网页版，也可以安装为 PWA；项目同时提供 Windows 和 Linux 桌面打包能力。

## 长版

沉浸式时钟希望把“看时间”变成一种安静的环境体验。它适合教室多媒体大屏、晚自习、自习室和个人桌面：远处能看清，长时间展示不喧闹，需要操作时又能快速唤出控制界面。

应用包含时钟、倒计时、秒表和自习四种模式。自习模式可以展示当前时间与日期、课程安排、多个目标日期、天气与降雨提醒、环境安静评分和多渠道语录；用户也可以关闭不需要的部分，只保留最适合现场的信息。字体、颜色、背景和主要组件均可调整，并支持导入本地背景和字体资源。

环境功能坚持诚实表达。噪音监测默认提供适合同一设备内比较的环境安静评分；完成外部参考声级校准后，才会显示估算 dB(A)。天气、在线语录和外部时间校准依赖网络服务，但核心时间功能与已有本地设置不要求账户即可使用。

沉浸式时钟可直接在浏览器中运行，支持 PWA 安装和基础离线资源，也提供 Windows 与 Linux 桌面构建。它不是完整日程平台或专业测量仪器，而是一块专注于时间、学习节奏和必要环境信息的轻量看板。

## 适合附在介绍后的要点

- 四种模式：时钟、倒计时、秒表、自习。
- 面向教室投屏、晚自习与个人专注。
- 课程、事件、天气、语录和环境信息按需组合。
- 本地优先，无需账户即可使用核心功能。
- 支持 Web、PWA 及 Windows/Linux 桌面构建。
