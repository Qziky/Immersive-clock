# 本地数据管理

本页描述“设置 > 设置数据”的存储所有权、备份协议、恢复语义和清理边界。实现入口为
`src/services/dataManagement.ts`，界面入口为
`src/components/SettingsPanel/sections/DataSettingsPanel.tsx`。

## 数据域与所有权

`dataDomainRegistry` 是应用数据边界的唯一清单。各域提供 `inspect`、`export`、`validate`、
`replace`、`clear` 和 `migrate`；未注册的同源键或缓存不应被清理操作删除。

| 数据域         | 所有内容与存储                                                                                | 默认备份   | 分类清理边界                                                                 |
| -------------- | --------------------------------------------------------------------------------------------- | ---------- | ---------------------------------------------------------------------------- |
| `settings`     | `AppSettings`、损坏设置隔离值及已登记的旧设置键；课程表、倒计时和本地语录属于设置内的用户内容 | 是         | 删除本域登记的设置键，不触碰资源、历史或未知键                               |
| `assets`       | IndexedDB 中的自定义背景和字体，以及旧字体键                                                  | 是         | 全部删除仅清本域；“未使用资源”只删除未被当前外观设置引用的资源               |
| `noiseHistory` | IndexedDB `noise-history` 中的噪声切片摘要；兼容旧 `noise-slices` 键                          | 仅完整备份 | 只删除切片和报告历史，保留噪声监测参数；不保存原始音频                       |
| `cache`        | 已知天气/语录缓存、接口退避状态、天气会话标记和已知 PWA 运行时缓存                            | 否         | 只删除白名单键、前缀和缓存名；保留设置、历史、设备种子、离线应用壳及未知缓存 |
| `diagnostics`  | 错误中心记录                                                                                  | 否         | 清空现有诊断记录，不改变记录功能                                             |
| `deviceState`  | 新手引导状态、接口设备种子、噪声报告图表偏好                                                  | 否         | 仅在“删除全部本地数据”中清理，不随缓存清理或备份迁移                         |

“删除全部本地数据”按上述六个域逐一清理，不调用 `localStorage.clear()`；其他应用或未来版本
尚未登记的同源数据保持不变。

## 备份内容

当前协议头为 `format: "immersive-clock-backup"`、`backupVersion: 1`，并记录应用版本、
导出时间、备份范围和分域 manifest。每个域单独携带 `schemaVersion`，协议版本与应用设置
版本彼此独立。

- “完整备份”包含规范化设置、自定义背景/字体及噪声切片摘要。
- “设置与资源”包含设置和自定义资源，不包含噪声历史。
- 两种范围均排除缓存、诊断记录、设备状态、PWA 缓存和原始音频。
- 设置导出会移除 `modifiedAt`、公告状态、递归的 `lastUpdated`、语录运行游标和已解析天气
  位置，并重置或移除校时结果；用户明确配置的偏好、位置输入和安全 HTTP(S) 接口仍保留。
- 备份文件是明文 JSON，可能包含位置、课程安排、语录内容和噪声活动时间，只应保存在
  可信设备上。

文件总大小上限为 150 MB，自定义资源合计上限为 100 MB；单个背景和字体上限分别为
20 MB 与 50 MB。恢复入口兼容当前 v1 数据包、旧 v2 设置包和旧版纯 `AppSettings`。

## 预检与恢复

文件选择后先检查大小并解析 JSON；支持 Worker 时由 `dataBackup.worker.ts` 完成文件读取与
解析，类型、版本、URL、资源 MIME/大小、重复资源和跨域资源引用仍在主线程统一校验。
确认前不会写入任何数据。

设置与自定义资源始终作为一个恢复单元，噪声历史可以取消选择。选中的域采用替换语义：

1. 再次校验已预检的数据包并保存当前设置、资源和所选历史作为回滚快照。
2. 导入备份资源；如选择噪声历史，以备份切片原子替换当前历史。
3. 最后提交设置，再删除备份清单之外的旧资源。
4. 任一步失败时，尝试恢复原资源、噪声历史和设置，并以 `RESTORE_FAILED` 报告结果。
5. 成功后由设置面板锁定操作并刷新应用，避免旧草稿重新写回。

未选择噪声历史时，现有历史保持不变。未来协议/域版本、损坏 JSON、不安全 URL、非法或
超限资源会在预检阶段被拒绝。

## 分类操作

- **清理临时缓存**：删除已知天气与语录缓存、接口阻断/退避状态、天气提醒会话状态和
  `local-webfonts`、`images-cache`、`fonts-cache`、`audio-cache`、`docs-cache`。设备种子、
  用户数据、未知键和 Workbox 离线应用壳不在该操作范围内。
- **清理噪声历史**：清空 `noise-history` 及兼容旧键，噪声阈值、校准和报告偏好不变。
- **清理诊断记录**：只清空错误中心记录。
- **清理未使用资源**：计算当前设置引用的资源 ID，只删除未引用的本地背景和字体。
- **恢复默认设置**：重置显示、提醒、天气、噪声和外观等偏好；保留课表、倒计时类型与
  条目、自定义倒计时、目标年份、语录配置、自定义资源和噪声历史。被外观重置解除引用的
  资源之后会显示为未使用资源。
- **删除全部本地数据**：清空六个注册域并刷新应用；未知同源数据仍保留。

## 噪声历史迁移

数据库版本 3 新增 `noise-history` Store，以稳定记录 ID 为主键，并为结束时间 `end` 建立
索引。`noiseSliceService` 的公开读取、追加、检查、导出、替换和清空接口均为异步：正常
追加只写一条记录，再通过时间索引删除超出保留期的数据，不再反复序列化完整数组。

首次使用服务时，如发现旧 `noise-slices` 数组，会先规范化记录并生成确定性 ID，再通过
IndexedDB 批量事务写入。事务完成后才删除旧键；若旧键因异常残留，下次迁移会以相同 ID
覆盖，因此不会制造重复记录。IndexedDB 初始化不可用时继续使用旧 localStorage 路径，
但正常浏览器主路径始终使用 IndexedDB。完整替换在单个事务中清空并写入新记录，失败时
原历史保持不变。
