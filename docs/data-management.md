# 数据管理

## 数据分类

| 分类           | 内容                                | 常规备份                 |
| -------------- | ----------------------------------- | ------------------------ |
| `settings`     | 应用设置与用户内容                  | 完整备份、设置与资源备份 |
| `assets`       | 自定义字体、背景及元数据            | 完整备份、设置与资源备份 |
| `noiseHistory` | 当前模型的派生环境安静评分          | 仅完整备份               |
| `cache`        | 可重新获取的缓存                    | 否                       |
| `diagnostics`  | 错误中心与诊断状态                  | 否                       |
| `deviceState`  | 引导状态、报告偏好和独立 dB(A) 校准 | 否                       |

常规完整备份中的噪音域使用 v4，只包含当前 `spectral-activity-v2` 派生评分，不包含 100 ms 原始特征帧。预检会明确拒绝包含 v1-v3 噪音域的旧备份；不含噪音域的设置与资源备份继续沿用现有兼容规则。

## 原始监测数据

100 ms 特征帧和会话元数据保存在 IndexedDB v7 的独立 Store 中，保留期固定为 14 天。界面显示列式数据实际占用和浏览器持久存储状态。浏览器不支持或拒绝持久存储时仍可采集，但数据可能受空间回收影响。

原始帧没有 localStorage 回退。关闭“保存监测数据”只停用原始帧和派生评分写入，不影响实时环境安静评分。

## .icnoise v1

`.icnoise` 是原始监测数据的专用二进制归档：

- 包含会话元数据和封存的列式 TypedArray 分块。
- 不包含 PCM。
- 支持按日期范围导出。
- 导入前检查格式、分块引用、会话/分块冲突和实际新增配额。
- 相同会话与相同分块可幂等导入；同 ID 内容不同则整次拒绝。
- 预检和写入分离，损坏文件不会产生部分写入。
- 导入成功后自动启动 `spectral-activity-v2` 后台重算。

## 清理

“清理噪音历史”会同时删除采集会话、100 ms 原始帧分块、派生评分和重算状态，但保留监测设置及独立 dB(A) 校准。清理结果会合并统计会话、分块、帧和评分占用；14 天自动清理使用同一数据边界。

“删除全部本地数据”还会删除设置、资源、缓存、诊断和设备状态。重置偏好不会删除历史、原始帧或校准。

## 迁移

v6 升级到 v7 时删除废弃的 `noise-history` Store 和全部非当前模型派生评分；当前模型评分、采集会话、特征分块及独立 dB(A) 校准会保留。新数据库不会再创建旧 Store。

应用启动后会以非阻塞、幂等方式清理旧 localStorage 噪音键、恢复中断会话并调度后台重算；即使监测开关关闭，重算也不依赖麦克风客户端启动。旧噪音域备份不会迁移，v1-v3 会在预检阶段明确返回“不支持旧版噪音数据”。

外观资源元数据迁移与噪音 Store 升级在同一数据库升级事务中保留。任何 IndexedDB 升级失败都不会回退到 localStorage 保存原始帧。
